# Provenance

Records of how Linux-derived code in this driver was produced.

- port_lcd_calc.manifest.json: the manifest the retired generator plan/ws031/handover/tools/retired/port_lcd_calc.py
  wrote when it extracted the Linux v6.8.12 display functions (source files, their sha256, the extracted
  functions).  The display code was rewritten by hand from that output during the i915 rebuild (S4); the
  generator is retired and the manifest is kept as the record of the original source.
