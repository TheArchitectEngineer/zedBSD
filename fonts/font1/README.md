# font1 — ASCII デザイン案 01

ユーザーの依頼「Monacoをベースにしつつ、古くさい記号をDroidベースにし、ASCIIはJetBrainsのクセのない感じと融合」を、画像生成による最初の字形案として保存したもの。

## デザインの方針

- **Monacoを骨格に**: 丸みのあるカウンター、高めの小文字、単層の `a`・`g`、読み分けやすい `I`・`i`・`l`、斜線入りの `0` を参考にした。
- **記号はDroid Sansを参考に**: `& @ ? , ; ( ) [ ] { }` などを、簡潔な線と素直な曲線で整理した。プロポーショナルの送り幅をそのまま使うのではなく、等幅の文字列に置く案として描いた。
- **JetBrains Monoの整理を取り入れる**: 英数字の端と直線を簡潔にし、形と太さを揃える方向。細長いスタジアム状の `O` や点入りの `0` は今回の方針に含めない。

## ファイル

- `glyphs/U0020.png`〜`glyphs/U007E.png`: 印字可能なASCII **95文字**の個別PNG。1024×1024、黒い字形、透明背景。SPACEは空の透明画像。
- `ascii-overview.png`: 保存した個別PNGから作った全95文字の一覧。コードポイントとベースラインガイド付き。
- `specimen.png`: 英数字・全記号・短いコード・文章・似た文字の見本。
- `comparison.png`: Monaco / font1 / Droid Sans / JetBrains Mono の同じ文字を並べた比較。
- `generated-atlas.png`: 組込み `image_gen` で生成した透明背景の原画像。10列×10行、1254×1254。
- `generation-prompt.txt`: 使用した最終プロンプト全文。参照画像は `../monaco-ascii/ascii-overview.png`、`../droid/ascii-overview.png`、`../jetbrains/ascii-overview.png`。
- `glyphs.json`: 文字とファイルの対応、原画像の切り出し範囲、参照フォントと原画像のSHA256、配置設定。

## 配置と確認

原画像から文字を切り出し、輪郭を変えずに全字形を7倍へ拡大して1024×1024へ配置した。行境界を越える `Q g p q y` などを切らないよう、連結した字形をまとめて抽出した。ベースラインは各行の下に伸びない文字の下端から推定し、y=745へ揃えた。比較用の送り幅はMonacoの460.875pxを仮置きしている。画像上の送り幅とベースラインは検討用の配置であり、確定したフォントのメトリクスではない。

文字対応と一覧を目視確認し、95文字のファイル数、SPACE以外の字形が空でないこと、上下に伸びる字形が途中で切れないこと、各画像端で切れないことを確認。文字列の見本も個別PNGから描画している。

この版は画像のデザイン案。個別PNGは原画像を拡大した参照で、1024px相当の細部が新しく得られるわけではない。TrueType化には輪郭の整形、実際の等幅への収まり、字面の大きさ・ストローク・カウンター・サイドベアリングの調整が必要。元の3書体は参照元として `glyphs.json` に記録している。
