# q1150-i01 — bounded implicit auto tracks in vertical-lr Grid

`layout/grid.c` now handles a limited 2×2 vertical-lr/LTR inline Grid with a definite content box, implicit auto rows/columns, zero gaps/frame/margins, one in-flow nonreplaced single ASCII text child per cell, auto child sizes, and start/stretch self-alignment. It measures each child's physical content width and natural inline advance, shares remaining room between each pair of auto tracks, maps logical rows to physical x and columns to physical y, and gives vertical text the resolved column height during layout. The path uses measured dimensions; it has no fixed 125px track value. Unsupported configurations retain the established path.
