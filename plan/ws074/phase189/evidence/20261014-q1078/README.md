# q1078-i01 — module script gap for 32 Grid testharness IDs

Pinned WPT `2d66b9b7998bb58c336138c178323ddee857b586`; fixed Grid selection 502 IDs and q1077 [results](../20261014-q1077/README.md). All 32 `no_output` rows are `css/css-grid/abspos/{orthogonal-positioned-grid-descendants,positioned-grid-descendants}-001..016.html`. Each document has an inline `<script type="module">` with the same named import `import {runTests} from "./support/positioned-grid-descendants.js";`. The imported file has one `export function runTests(...)`, plus top-level const arrays and loops. It calls `document.fonts.ready.then(() => checkLayout(".grid"))`. The 32 test variants pass different arguments; none has a different import shape. This was verified by enumerating every `no_output` report row in q1077's four shard `report.json` files and reading the pinned WPT source.

Browser path: `page/script.c:script_type_runs` accepts classic JavaScript MIME types only and returns false for `module`; both parser-inserted and dynamic script paths skip it. `bind/window.c:bind_run_script` passes `how=0` to `js_run_script`, so it runs classic scripts. JS parser accepts `JS_PARSE_MODULE`, and `browser --dump=ast --module` successfully parses the shared WPT module (exit 0, AST begins `Program strict module`), but `js/compile.c:compile_statement` sends module declarations to `js_compile_unsupported(..., "modules")`. The script tool exposes `--module` only to AST dump, not execution. Thus enabling the HTML type alone cannot execute imports/exports.

Implementation boundary: introduce module compilation/evaluation support and HTML module loading together, with module-relative resolution, named export/import binding, separate module scope, once-per-module evaluation and error propagation. Preserve classic script behavior. First finite implementation can establish standalone module execution and explicit unsupported import reporting; a later finite implementation can add graph linking for the named import used here. Neither partial capability is evidence of PASS for these 32 IDs. A fixed representative (`positioned-grid-descendants-001.html`) should move from `no_output` to a real WPT completion before a 32-ID recensus. General module tests must cover strict scope, load ordering, fetch/error and duplicate evaluation. Full ES module semantics (cycles/live bindings/top-level await) need separate design and verification.
