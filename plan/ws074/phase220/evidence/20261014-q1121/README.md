# q1121-i01 — vertical text geometry diagnosis

After q1120, fixed column-axis positioned-items 012–016 each have horizontal LTR/RTL callbacks PASS and vertical-lr/rl callbacks FAIL. The first vertical assertion in all five is the Ahem `X XX X` absolute child's border width: expected 10px, observed 60px. The WPT expectation is a 10px physical line width and 60px physical inline advance; its columns progress down the page and rows across it.

The [minimal non-Grid fixture](vertical-text.html) with 10px monospace text shows that both `vertical-lr` and `vertical-rl` still produce a horizontal text line. The absolute children are 36×10px, while the 100×100px ordinary blocks contain a line progressing along x. [Host layout](vertical-text.layout.txt). The earlier [minimal positioned-Grid fixture](../../../phase217/evidence/20261014-q1092/vertical-grid-cases.html) separately shows the same horizontal line inside Grid. Together they isolate inline layout before Grid track axis mapping and confirm the q1103 design finding on the q1120 final source.

Source trace: `layout/inline.c` cuts against physical `box->width`, stores fragment x and line y, stacks lines downwards, and sets block height from the line cursor. `layout/position.c` derives an absolute text box's auto physical width from the horizontal last fragment. `paint/list.c` sends glyph advances along x to a `PAINT_TEXT` item; CPU/GPU paint implementations have no glyph rotation field. Bounds, hit testing, and dumps likewise consume the horizontal fragment geometry. `text-orientation` is absent from the CSS property table. [CSS Writing Modes Level 3 §5.1](https://www.w3.org/TR/css-writing-modes-3/#text-orientation) defines sideways as a horizontally composed run rotated 90° clockwise; [§6–7](https://www.w3.org/TR/css-writing-modes-3/#abstract-box) maps logical inline/block dimensions to physical axes.

Next finite implementation scope: add a coherent vertical line/fragment representation and sideways text paint for one unwrapped LTR text run in a non-Grid `vertical-lr` block with explicit physical height, no floats/atomic descendants. Verify the physical width equals 10px line height and physical height equals glyph advance (36px in this fixture; Ahem 60px in WPT), plus paint/bounds/hit/dump and horizontal regression. The broader vertical-rl, wrapping, mixed orientation, Grid track mapping and absolute positioning remain later finite scopes; q1122 must not claim WPT whole PASS from the first stage alone.
