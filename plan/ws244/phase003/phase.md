## 実行の記録（2026-10-18）

### 段 1: Linux の名前の macro の改名（済み、commit は下）

- gt-regs.h・gt-power.h・mocs.h・workarounds.h の Linux の名前の macro に `I915_GT_`、commands.h に `I915_CMD_`（`__INSTR` → `I915_CMD_INSTR`）、pci-ids.h の `INTEL_*_IDS` を `I915_PCI_*_IDS` にした。全部で 521 の名前、対応は [rename-map.txt](rename-map.txt)。lrc-offsets.h は既に `I915_LRC_*`。既存の名前との衝突は無い（src・include・userland を grep）。
- 置き換えは src/drivers/gpu/i915 と include の .c・.h・.inc の識別子だけ。`Values referenced:`・`Procedure referenced:` の block（Linux の名前を引く所）と文字列の literal（log の文言）は変えていない。行は増減していない。
- 動作の確かめ: 置き換えの前と後で、amd64 の既定と I915_TESTS=y の build の i915 の object（124 個と 535 個）の SHA-256 を比べた。device.o 以外はすべて一致した。device.o は bitcode を IR にして比べると、違うのは inline asm の srcloc の metadata（前処理後の文字の位置）の 2 つだけで、code は同じ。GT の register の書き込みの列は object が同じなので変わらない（mmio-record の比較の代わり）。
- build: 両方の組で rc=0、warning 0、`amd64 vmunix check: PASS`。

### 段 2: 先頭の表示と block ごとの referenced（2026-10-18 済み）

- 14 file（gt-regs.h・commands.h・gt-power.h・lrc-offsets.h・mocs.h・workarounds.h・pci-ids.h・mocs-table*.inc・mcr-ranges.inc・engine-table*.inc・forcewake-ranges*.inc）の先頭の Intel・Tungsten Graphics の Copyright と MIT の許諾、「Modified for zedBSD: excerpted …」・SHA-256 の一覧・Rewrites の行・「Generated by gen-inc.py」を外し、zedBSD の表示（Zlib）と役割の説明だけにした。file の途中の同じ形の block（Gen9 の追加の節）も説明だけにした。
- block ごとに `Values referenced:` を付けた。gen-inc の `/* <path>:<行> */` の comment（v6.19 の行）は `Values referenced: Linux v6.19 <path> (<Linux の名前>)` に、手で抜いた節（6.8.12）の block は Linux 6.8.12 の tree で `#define` を引いて path を決め `Values referenced: Linux v6.8.12 …` にした。**v6.19 と書いた物は手元に v6.19 が無いので照合していない（未確認）**。6.8.12 に無い名前（GEN9_FF_SLICE_CHICKEN ほか、GEN12_MOCS_UC_INDEX ほか、INTEL_CML_IDS など）は zedBSD が足した名前で、block の referenced に含めていない。
- 残っていた Linux の名前の 14 個（I915_GEM_HWS_*、I915_HWS_CSB_*、I915_GTT_PAGE_SIZE_4K、I915_PDES、I915_PDE_MASK、I915_ERROR_INSTRUCTION）と lrc-offsets.h の表の名前 4 つ（gen12_xcs_offsets など → i915_lrc_gen12_xcs など）を改名した（rename-map.txt の末尾）。I915_MAX_VCS は device-info.c にも定義があるので p004 に残した。
- mocs-table*.inc の行ごとの comment（「Base - L3 + LLC」など）は Linux の intel_mocs.c の comment と同じだったので消した。engine-table*.inc の行ごとの Linux の base の名前の comment も消し、名前は block の referenced に移した。engine-table の行の形（id・class・instance・base・name の 1 行）は Linux の struct engine_info（class・instance・mmio_bases[]）と形が違う。
- 動作の確かめ: 14 file の comment を除いた code の行を、改名の対応を当てた前の版と比べて全部一致（`differ 0`）。
- build: amd64 の既定・I915_TESTS=y とも rc=0、warning 0、PASS。`git diff --check` 空。
