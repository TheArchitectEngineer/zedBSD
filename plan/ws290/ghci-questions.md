# GHCI 2.0（docs/ghci.md）への疑問の一覧

- 対象: amaterrace-gpu の `docs/ghci.md`、commit **4d12da1**（2026-10-26。be3cf15 と docs/・include/ の差は無い）。行の番号はこの commit の物。
- 出どころ: zedBSD の GHCI の driver を GHCI 2.0 だけに書き直す設計（zedBSD の WS290 p001、[design.md](design.md) §19）。driver を書くのに、ghci.md の 2.0 の部分だけでは決まらない点・食い違う点を挙げた。
- 各行の「driver の推し」は zedBSD の driver の側から見た案で、決めるのは GHCI の設計者。推しのまま採るか、別の答えにするかを行ごとに答えてほしい。
- 重さ: **C** = 決まらないと draw・表示・VM が書けない、**H** = driver の振る舞いが決まらない、**M** = 推しで進めるが確かめが要る、**L** = 文の直し。内訳は C 10・H 13・M 13・L 3 の 39 件。
- 「止まる Phase」は zedBSD の WS290 の実装の段（p002 語の層、p004 core、p005 memory と VM、p006 compiler、p007〜p009 Vulkan の executor、p010 discrete、p011 表示）。p002・p003 は回答なしで始められ、p004 は G04 が要る。
- 回答を急ぐ順の案: G04 → G05・G06・G07・G08・G32・G36 → G18・G19 → G20〜G25・G35・G37 → G28・G31。
