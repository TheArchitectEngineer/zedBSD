# BUG-361: NVIDIA RTX 2070（nvrtx）で Notes が起動しない（nvrtx の Vulkan の executor に stencil の format と test が無い）

- 状態: reproduced（実機、2026-10-30 P5 q1692-i01）。登録: 2026-10-30 Q1（ユーザー「NVIDIA RTXを使っているときにNotesアプリが起動できるか確認し、できなければ対応しておいてください。」）
- 再現: 10.0.10.3 の RTX 2070、kernel 3605640992（main＋WS243＋試験の入力の注入）、machine の userland の `/bin/notes`（cksum 2430934716）。出力は `NOTES TABLET seat` の後 `notes: stencil format failed (-11)` で終わり、窓は出ない（KWL FAILED 0、kernel の失敗 0）。記録 `build/ws243/q1692-n1`（P5 の worktree）。
- 原因: Notes の renderer（`userland/desktop/notes/render.c` の `render_stencil_format`）は線の塗りに stencil の format（D24_UNORM_S8_UINT・D32_SFLOAT_S8_UINT・S8_UINT・D16_UNORM_S8_UINT のどれかで optimal の DEPTH_STENCIL_ATTACHMENT）が要る。nvrtx の executor は depth を D32_SFLOAT だけ持ち stencil が無い（`src/drivers/gpu/nvrtx/vk/` の vk-device.c の format の表、vk-pipeline.c が stencilTestEnable を拒む、exec-push.c が STENCIL_TEST を常に false、vk-target.c が depth の attachment を D32_SFLOAT に限る）。i915・amdrdna・Venus は stencil を持つ。
- 直す方針: nvrtx の中で D24_UNORM_S8_UINT（zeta の Z24S8）を depth-stencil の attachment として出し、image・view・render pass の stencil の aspect、load の clear、pipeline の stencil の状態（front・back の op・compare・mask・ref、dynamic state）を 3D の method に（Mesa nvk の値を参照）。HAL は変えない。
- 担当: P5（q1692-i01）。
