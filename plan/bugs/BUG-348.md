# BUG-348: warm reboot（Linux の後）で USB の LAN（RTL8156、usb-cdc-ncm の ue0）の link が上がらず、zedBSD が network に出てこない

- 状態: open（2026-10-28 Q1 が登録。担当は未定）
- 発見: 2026-10-28 WS291（P2、q1645）。RDNA の機械 10.0.10.3 で、Debian から BootNext で zedBSD に再起動した後に応答しない事が 4 回（04:10・06:37・08:08・08:51）。
- 観測: zedBSD の /boot/boot0/log の失敗の boot（boot-000147、boot-000154）は kernel・desktop・GPU は動き続けていたが、`usb-cdc-ncm: ue0 link 2500 Mb/s` の行が無い（mac の行までは出る）。正常の boot（boot-000148、boot-000155）は必ず link の行がある。link が上がらないので DHCP・SSH が無く、外からは止まったように見える。
- 見込み: Linux の r8152・cdc_ncm が使った後の USB NIC の状態が warm reboot で残り、zedBSD の usb-cdc-ncm が link を上げられない。
- 期待: warm reboot の後でも link が上がる（一定の時間で上がらなければ port reset・SET_CONFIGURATION をやり直すなど）。
- 回避: WS291 の measure.sh で、BootNext の前に Debian の側で USB NIC を driver から外して reset する（P2）。
- 証拠: P2 の worktree の 10.0.10.3 の boot の log（plan/ws291/phase006/phase.md に path）。
