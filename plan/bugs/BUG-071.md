# BUG-071: FAT で file を作ると、要求の mode・所有者が mount の見せる値と違えば EOPNOTSUPP で失敗する

Bug ID: `BUG-071`
Reproduction: reproduced（QEMU、WS073 の agent、ws073-p009 の作業中。既存の不具合、普通の `mount -t auto` の FAT でも）
Disposition: scheduled（ws073-p010）
Date: 2026-09-27
Source: ws073-p009（`/boot`・`/boot/esp` の公開）
Owner: WS073

## 期待と観測

期待: FAT（ESP の `/boot/esp`、USB stick）で `echo x > file`・`touch`・`cp` が file を作れる。FAT は mode・所有者を持たないので、作成は受け入れ、
mount が見せる mode（0755 root:wheel）で見せる（FreeBSD の msdosfs と同じ）。

観測: file の作成が EOPNOTSUPP。mkdir は通る。`src/drivers/fs/fat.c` の `fat_creation_representable()` が要求の mode・所有者と見せる値の
完全な一致を要る。
