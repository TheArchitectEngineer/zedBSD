# BUG-204: Phone の app で画面 keyboard の日本語のフリック入力が無視される

Reproduction: reproduced（ユーザー、Windows の QEMU（Venus）で uat-0505g、2026-10-05 夜 UAT）
Disposition: tracking
Discovery: 2026-10-05 夜 ユーザーの UAT のコメント
Handling: WS170・WS102（画面 keyboard）

## 観測

ユーザー「Phoneアプリでオンスクリーンキーボードを試したところ、日本語フリック入力が無視されて入力できなかった。」

## 原因と修正（2026-10-06 P1）

BUG-203 と同じ根。zdesktop の画面 keyboard は US 配列の文字を key で、それ以外（かな）を text-input の commit（濁点などは delete と commit）で送る
（`userland/desktop/wayland/keyboard.c` の `keyboard_send`）。Phone の `kl_field` に text-input の口が無く、text-input も enable されないので、かなは捨てられていた。
修正・試験・T1 への依頼は [BUG-203](BUG-203.md)。host 試験の flick-voiced（「か」の後に delete 3 byte と「が」の commit）が PASS。
