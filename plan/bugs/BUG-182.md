# BUG-182: Browser: タップがクリックにならず、HTML の中のボタンを押せない

Reproduction: reproduced（実機）
Disposition: tracking（優先度: 高）
Discovery: 2026-10-04 夜 ad-hoc UAT-3（実機 Latitude 5330、image `build/uat-3/hdd-image.img` sha256 ada4492e…、main efe846a、[uat.md の uat-3](../uat.md)）
Handling: WS074（Browser、Codex の担当）／browser の shell の touch の入力の変換（WS107 の libbrowser の public input interface）

## 観測

ユーザー「ブラウザでタップがクリックにならず、HTML中のボタンを押せない。」

## 次

shell が Wayland の touch の event（down・up）を libbrowser の pointer の click に変換していない、または libbrowser が touch を click の合成（mousedown・mouseup・click）に結んでいない疑い。 WS074（Browser）は Master で「Codex が担当」（このセッションの担当の外）。担当はユーザーが決める。
