# BUG-046: `POSIX-R2.ELF` の SIGEV_THREAD の timer の試験が console で走らせると EINTR で落ちる

Bug ID: `BUG-046`
Reproduction: reproduced（QEMU、amd64 guest、console（serial mirror）で 4/4。SSH では 3/3 通る）
Disposition: resolved（2026-09-27、ws056-p002。console の `POSIX-R2.ELF` の status 0 は別の停止が残る）
Date: 2026-09-25
Source: ws056-p001（q423-i01）で、BUG-042 を直した `POSIX-R2.ELF` を console で走らせたとき（`conformance-identity` が stdout = `/dev/console` を要るため）。
Owner: ws056-p002
Queue: none。

## 期待と観測・影響

期待: `sem_timedwait()` は timer の callback が `sem_post()` するまで待ち、EINTR で戻らない（program は handler を持つ signal を受けていない）。

観測: console で `POSIX_R2_FAIL: thread-timer-callback errno=7`（EINTR）または `thread-timer-multiple-callback errno=7`（どちらになるかは回ごとに違う）。stdin を `/dev/null` にしても、stderr を file にしても同じ。
SSH（`guest.py run`、stdout は pipe）では同じ ELF・同じ image で timer の試験を通り `conformance-identity` まで進む。
libc の worker（wake signal 63 を unblock）以外の thread は 63 を block しており（`__libc_init`）、kernel の `signal_send_process_info()` は signal を unblock している thread だけを `sched_interrupt` する。
main thread の `sem_timedwait` が EINTR になる経路は未特定。console と SSH の違いは tty（foreground の process group、行ごとの同期の出力による timing）。

影響: `POSIX-R2.ELF` は console で status 0 にならない。SIGEV_THREAD の timer を使う program が tty の foreground で EINTR を見る可能性。

## 再開の条件

libc の signal・timer を扱う WS で。手掛かり: `sem_timedwait` の usync の wait が EINTR を返した時の main の pending signal と mask を kernel 側（gdbstub）で見る。受け入れ案: console で 5 回連続 status 0。

## 解決（2026-09-27、ws056-p002）

原因: `sigprocmask(SIG_SETMASK)`（`pthread_sigmask` も）・`sigsuspend`・`ppoll`・`pselect` が program の mask を public の bit で切って渡していたので、
置き換えの mask で予約の wake signal 63 が program の thread で unblock され、kernel が timer の wake をその thread に渡して待ちが EINTR になった。
修正: libc（`signal.c`・`poll.c`）で置き換えの mask に thread の今の予約の bit を保つ（`__libc_signal_mask_keep_reserved()`）。

証拠（QEMU、amd64 の hybrid の guest、[phase](../ws056/phase002/phase.md)）: `plan/ws056/tests/sigev-thread-mask.c`（mask を空に置き換えてから SIGEV_THREAD の
timer を待つ 300 回）が修正前 EINTR 155・29・92/300 → 修正後 0/300 ×3。console の `POSIX-R2.ELF` は `R2:TIMER:PASS`（2/2）。実機は未実施。

残り: console の `POSIX-R2.ELF` は timer の後、最後の `execve("/bin/sh")` の後で止まる（2/2）。EINTR とは別の不具合として追跡する（ID は main が割り当てる）。
