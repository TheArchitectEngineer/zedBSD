# BUG-252: App Home の animation が pointer の事象が無いと終わらない（Calendar の icon の位置で止まる、i915 実機）

- 状態: reproduced（実機 5330、ベアメタル、i915、ユーザーの UAT 2026-10-07） / scheduled（P2）
- 発見: 2026-10-07 ユーザー「App Homeで、マウスを動かしてイベントループを回さないと、アニメが終わらないです。Calendarのアイコンの位置でアニメがとまります。i915実機ベアメタルです。」

## 疑い（Q1、未確認）

- BUG-246（整列の animation、cfdb21813）と同じ種類: App Home の animation（ws181-p008 の奥へ・奥からの遷移、または app を開く時の icon からの拡大）が次の frame を描画の中で `dirty` にして頼み、compose.c が submit の後で消すので、次の frame は入力の時だけ。Venus の QEMU では client の commit で frame が回り隠れる。
- 「Calendar の icon の位置で止まる」: icon から窓が広がる（または縮む）animation の途中で止まっている可能性。
