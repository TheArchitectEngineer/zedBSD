# BUG-299: Intel AX211 の起動時の LTR（CSR 0x0d4）と SOC_CONFIG の flag が Linux と違う

- 状態: unknown（実機で影響を見ていない） / tracking
- 発見: ws218-p002（P3、2026-10-13）。出典の comment を書く時に Linux iwlwifi v6.17 の field の配置と照らして気づいた。動作は変えていない。
- 観察:
  1. LTR: 起動時に CSR 0x0d4 の no-snoop の半分に 0x82fa を書く。Linux の field の配置では scale 0・value 762（762 ns）と読めるが、Linux は約 256 µs を書く。
  2. SOC_CONFIG の flags 0x0a: discrete の bit（bit 0）が 0。Linux は discrete の部品で 1 にする。試験の機械（5320・5330）の AX211 は CNVio2 の部品なので 0 が正しい可能性がある。
- 影響（推測）: 1 は省電力の待ちの値で、電力か遅延に効く可能性。2 は部品の種類の申告。今のところ実機で不具合は報告されていない。
- 次: 実機（5320・5330）での WS218 p002 の回帰の時に、省電力と scan・接続を見る。直すなら公開の資料か実機の観測を出典にする。
