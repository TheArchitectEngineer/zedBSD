# BUG-068: console の `POSIX-R2.ELF` が最後の `execve("/bin/sh")` の後で止まる

Bug ID: `BUG-068`
Reproduction: reproduced（QEMU、amd64 の hybrid guest の console、2/2。salvage の片付けの agent）
Disposition: tracking
Date: 2026-09-27
Source: [ws056-p002](../ws056/phase002/phase.md)（BUG-046 の修正の後の console の試験）
Owner: 未定（WS073 の候補）

## 期待と観測

期待: console で `POSIX-R2.ELF` が最後に自分自身を `R2_EXEC_FINAL=1` で `execve` し、`R2:01-06:PASS` を出して status 0 で終わる。

観測: timer（`R2:TIMER:PASS`）・WNOWAIT・tmpfs・lock・NOFILE・`posix_spawn` まで通り（診断の印 M1〜M6 で確認）、最後の `execve` の後で止まる（2/2）。
BUG-046 の修正（libc の予約の signal 63 の bit を保つ）の前は timer で落ちていたので、この停止が修正より前からあったかは分からない。

## 仮説

SIGEV_THREAD の worker の thread が生きている多 thread の process の `execve`（他の thread の後片付け、または予約の signal の状態の引き継ぎ）。未確認。

## 影響

BUG-046 の受け入れの案（console で 5 回続けて status 0）と ws056-p001 の clear を満たせない。

## 次の手

多 thread の process の execve の最小の再現（`plan/ws056/tests/spawn-probe.c` の近く）を作り、gdbstub で止まった位置を見る。
