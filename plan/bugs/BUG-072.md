# BUG-072: zedBSD が FAT32 に書いた directory・file の metadata が仕様に合わない（`..`、FSInfo、日時）

Bug ID: `BUG-072`
Reproduction: reproduced（QEMU、WS073 の agent、BUG-071 の確認の中。既存の不具合）
Disposition: scheduled（ws073-p012）
Date: 2026-09-27
Source: ws073-p010（BUG-071 の確認）
Owner: WS073

## 期待と観測

期待: zedBSD が FAT32 の volume に directory と file を作った後、host の `fsck.fat -n` が誤りを出さず、mtools が正しい日時を出す。

観測（データは正しい、`cmp` 一致）:

1. 「Invalid '..' entry in the second slot」: 最上位の directory の `..` に root の cluster（2）を書く（仕様は 0）。
   `fat_raw_initialize_directory()` と rename の `fat_raw_update_dotdot`。
2. 「Free cluster summary wrong」: FSInfo の空き cluster 数を保っていない。
3. 新しい entry の作成・更新の日時が 0（mtools で 1980-00-00 0:00、不正な日付）。
