# BUG-309: PC-9821 Ra43 の BIOS が zedBSD の pc98 の disk を起動の disk と認識しない（0x55AA の印の疑い）

- 状態: reproduced（実機、ユーザーの UAT）/ scheduled（2026-10-14 Q1、P1）
- 発見: ユーザーの UAT（2026-10-14）「PC-9821 V13では起動OKでした。PC-9821 Ra43では、起動ディスクとしてBIOSから認識されませんでした。55 aaのマーカーがあるとRa43では認識されないと記憶してます。直せますか？」
- 手がかり（Q1、source の grep だけ）: `tools/build/zedimage-host.c` は MBR の sector の 510・511 に 0x55・0xAA を書く所が 2 か所（389 行・644 行付近）と、stage1 にその印を求める検査（330 行）がある。pc98 の image でどの経路を通り、sector 0 に 0x55AA が残るかは未確認。PC-98 の IPL は sector 0 にあり、PC/AT の MBR の印は要らない。
- 次: P1 が pc98 の image の sector 0 の作り方を調べ、pc98 では 0x55AA を書かない（PC-98 の IPL と disklabel だけ）形に直す。V13 で起動できることを保つ。
- 関連: WS232（pc98 の build と QEMU の起動）、platform/pc98。
