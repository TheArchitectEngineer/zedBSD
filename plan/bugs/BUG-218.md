# BUG-218: Phone の本体の周りに padding がある（Settings と同じにして padding なし、title bar との隙間も Settings と同じ）。慣性 scroll の開始が swipe から約 300 ms 遅れる（50 ms 以内、最大 80 ms）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS170（Phone）

## 観測（ユーザー）

「Phoneアプリはウィンドウタイトルバーとくらべて本体が小さく、周囲にパディングがあるかんじです。これはSettingsと同じにして、パディングはなしにして、タイトルバーとの隙間もSettingsと同じにしてほしいです。Settingsは単純にパディングがなく、スペースはデコレータの規定値だと思います。／Phoneアプリで慣性スクロールが効きました！でも、スワイプ動作から300msくらい遅れてスクロールが開始します。これは可能な限り小さく、50ms以内にしたいです。どんなに遅くても80msです。」

## 次（未確認の見込み）

padding は Settings に合わせる。scroll の開始の遅れ（gesture の判定の待ち・frame の待ち）を測り 50 ms 以内に（最大 80 ms）。慣性は BUG-211 の共通の実装に寄せる。
