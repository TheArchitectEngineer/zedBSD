# BUG-323: RTX 2070（nvrtx）で cursor が黒く、色が逆になる

- 状態: reproduced（実機、ユーザー）/ tracking（記録だけ、2026-10-15 ユーザー「BUGとして記録だけでいいのですが」）
- 発見: 2026-10-15 夜 ユーザー「RTX 2070で、カーソルが黒で、色が逆でした。」（RTX 機 i5-13400F＋RTX 2070、main 5ac66395e ごろの image、cold boot の確かめの時）。
- 関連の code（Q1 の読み、未解析）: `src/drivers/gpu/nvrtx/cursor.c` の hardware の cursor は 64x64 の A8R8G8B8・premultiplied alpha。色の並び（ARGB/ABGR）か alpha の扱い（premultiplied か straight か、反転）が compositor の渡す形と合っていない見込み。
- 関連: [BUG-324](BUG-324.md)（同じ cursor の動きの滑らかさ）、WS037（nvrtx）。
- 次: nvrtx の作業を再開する時に、compositor が渡す cursor の image の形と nvrtx の cursor の surface の形を照らす。
