# BUG-249: 5320 で Restart が終わらない（「Restart」の popup のまま）、Power Off はできる

- 状態: reproduced（実機 5320、ユーザー 2026-10-07） / scheduled（P2、fallback を実装済み・実機の確認待ち）
- 発見: 2026-10-07 ユーザー「5320でPower Offはできたが、Restartはできなくて、Restartのポップアップのまま処理しつづけました。」

## 疑い（Q1、未確認）

- `src/kern/platform/pcat.c` の `kern_platform_reboot` は keyboard controller の reset（port 0x64 に 0xfe）だけを試し、効かなければ halt する。ACPI の FADT の RESET_REG（多くは port 0xcf9 に 6）や port 0xcf9 の直接の reset、triple fault の順の fallback が無い。Linux の既定は ACPI の reset → keyboard → ... の順。Dell の TGL の機種で 8042 の reset が効かない可能性。
- または reboot の前の shutdown の道（driver の停止・sync）で止まっている。halt なら画面は最後の絵（popup）のまま。

## 次

- 5320 の次の起動で /var/log/kernel.log・messages の Restart の時の行（shutdown の進み）を読む（log が書けていれば）。
- FADT の RESET_REG を読み、ACPI の reset → 0xcf9 → keyboard の順に試す fallback を pcat.c に足す（HAL の API は変えない）。5330 で reboot が今どおり効くこと（ws084 の reboot-loop.sh）も確かめる。

## 直し（2026-10-07 P2、q854-i01）

- `kern_platform_reboot`（`src/kern/platform/pcat.c`）は ACPI の FADT の reset register → chipset の reset control register（port 0xcf9）→ keyboard controller の順に試し、それぞれの後に 100 ms 待つ（`kern_rtc_read_counter` で。counter が無ければ port 0x80 の読みの回数で）。全部で reset しなければ今どおり halt。0xcf9 は SYS_RST+FULL_RST を書いてから RST_CPU の立ち上がりで始める（電源を回す cold reset）。各段の失敗は `platform: reboot: ...` を log に出す。
- ACPI の側（`src/drivers/acpi/acpi-event.c`、宣言は `include/drivers/acpi/acpi.h`、HAL の API は変えていない）: `drv_acpi_events_init` が FADT の RESET_REG（offset 116 の GAS）と RESET_VALUE（offset 128）を、flags の RESET_REG_SUP（bit 10）が立ち I/O 空間の時だけ読み（hardware-reduced の時も）、`ACPI: reset register port 0x.. value 0x.. width ..` を log に出す。`drv_acpi_reset_machine()` は AML を評価せずに値を port に書くだけ（device の停止の後でも呼べる）。名前は既存の `drv_acpi_reset()`（namespace を空にする）と分けた。memory・PCI の config 空間の register は使わない（log に出す）。
- 5330 の FADT（`plan/ws049/tests/latitude5330/facp.dat`）の RESET_REG は SystemIO・8 bit・port **0xB2**（SMI の command port）、値 **0x73**、flags 0x0020C4F5 の bit 10 が 1。Dell の reset は firmware への SMI の頼み。5320 は FADT を取っていないが同じ Dell の作りと見る（未確認）。
- 確かめ: kernel（`make -j16 ZEDBSD_CONFIG=config/current-uat.mk BUILD=build/bug250 vmunix`）warning 0、include check・vmunix check PASS、cksum `2674080499 3148104`（BUG-253 と eDP の直しも含む）。host の `plan/ws052/tests/run-host-sleep.sh`（acpi-event.c を含む）PASS。実機・QEMU は未実施: 5320 で Restart が終わって再起動すること、5330 で Restart が今どおり効くこと（ws084 の reboot-loop.sh）、boot の log に `ACPI: reset register port 0xb2 value 0x73 width 8` が出ること。QEMU（q35 の FADT は 0xcf9・値 6）の Restart。
