# BUG-066: pcat（i386、legacy の overlay の起動）が overlay-data の mount で EBUSY になり起動しない

Bug ID: `BUG-066`
Reproduction: reproduced（QEMU、BIOS/IDE、WS036 の agent と WS073。決定的）
Disposition: resolved（ba99a981、WS072 の作者の修正を採った。WS073 の 1023485a は merge しない）
Date: 2026-09-27
Source: WS036 の agent の pcat の boot test（main から WS073 へ転送）
Owner: WS073

## 期待と観測

期待: `config/ci/config-pcat.mk`（firmware 無し）の image が `BOOT_MODE=bios-ide plan/tools/boot-test.sh` で login prompt に届く。

観測（画面の最後）:

```
vfs: loop1 <- boot0:data.img (private, read-write)
loop1: write block=128 count=16 flags=2 error=17
vfs: mount overlay-data image failed (error 17)
VFS initialization failed (17); entering idle
```

error 17 はこの tree の `EBUSY`（`include/uapi/errno.h`）。良: main 3231b05f（＋ws036-p021）。悪: main e2750963（＋p021）。amd64 の NVMe・pc98 は起動する。
WS073 でも 2026-09-27 に再現（`build/ws073-pcat/boot-test/login.png`）。BUG-065 の変更（`mount_disk_reserve`）を外した kernel でも同じ。

## 次の手

WS073 の phase で、3231b05f..e2750963 の kernel の差分（`buf.c`・`file.c`・`ufs.c`）を切り分けて直す。
