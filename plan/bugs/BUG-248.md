# BUG-248: Text Editor のメニューが他の app と違う独自の形（下線の付いた共通のメニューに）

- 状態: reproduced（ユーザーの UAT、2026-10-07） / tracking（担当は後で決める）
- 発見: 2026-10-07 ユーザーの UAT

## 観察（ユーザーの文）

「Text Editorのメニューがアドホックすぎます。ほかのアプリと同じように、下線のあるメニューで作ってほしいです。」

## 次

- `userland/desktop/textedit` のメニューを、他の app（Files・Settings・Notes など）と同じ libkeiland の共通のメニュー（accelerator の下線の付いた menu bar）で作り直す。項目と短縮 key は今の物を保つ。試験は master の Tools の Text Editor の試験（plan/tools/textedit）を追従させる。
