# BUG-235: Log Out の icon で確認なしに session が終わる（desktop を暗くする演出で、終了するか選ばせる）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS099・WS131

## 観測（ユーザー）

「ログアウトアイコンで、確認なくセッションが終了してしまいます。デスクトップを暗くする演出で、終了するか選ばせてください。」

## 次（未確認の見込み）

Log Out で desktop を暗くし、確認の dialog（Log Out・Cancel）を出す。電源 button の dialog（WS132 p008）と同じ形に。

## 2026-10-06 ユーザーの追加

「Logoutの確認は、電源オフのボタンもあるといいですね。また、タブレットで使うのが目的なので、Logoffというアイコンより、Power Offみたいなアイコンとテキストがいいかもしれないです。」→ App Home の Log Out の icon を **Power Off（電源の記号と「Power Off」の文字）**に替え、押すと desktop を暗くして **Power Off・Restart・Log Out・Cancel** を選ぶ（電源 button の dialog と同じ形）。設計は ws099-p037。
