Bug ID: `BUG-080`
Reproduction: reproduced（host、決定的。db99dda6 でも同じ＝既存）
Disposition: tracking（1 つ目の誤りは修正、2 つ目はユーザーの判断待ち）
Date: 2026-09-28

## 観測

`make menuconfig-host-test` が MAC-T001 で失敗: expat の package が `packages/libs` にあり、menu がその分類を出さない。WS035 の変更の前の
main（db99dda6）でも同じ。

## 次の手

menuconfig の package の分類の一覧に `libs` を足すか、expat の置き場を既存の分類に合わせる。menuconfig の host 試験を通す。

## 経過（2026-09-28、WS073）

- 修正: `tools/menuconfig.py` の PACKAGE_CATEGORIES に `("Libraries", "packages/libs")` を足した。expat・zlib が menu から届く。
- 次の誤り（判断待ち）: `MAC-T001: egltest is offered only on amd64`。試験（menuconfig-target-host-test.py の 73〜78 行）は base と package の
  program が全 platform（`*`）で選べることを求める（「program は platform ではなく構成する人が選ぶ」）。違反は 37 行: desktop・GPU の一式
  （libvulkan、libwayland-*、zdesktop*、sessiond、probe、gpu-* の試験など 35 行、build の規則は platform/amd64/vmunix.mk だけ）、noct（amd64 i386 pc98 rpi4）、
  zedinst（amd64 i386 pc98）。この check を飛ばすと MAC-T001 の残りは PASS。
- 選択肢（main 経由でユーザーへ）: A 試験を緩める（build の規則がある platform に限るのは許し、どこでも build できる program の制限だけを誤りに）、
  B 方針を保ち行を `*` にし、validate-image-config が build できない選択を拒む、C そのまま判断待ちとして記録。既定の提案は A。
  判断までは check を変えない。

（上の選択肢は下の判断で置き換わった。）

## 判断（2026-09-28）

ユーザー:「base, desktop, firmware, packagesに分けましょう。」→ user program を Base・Desktop・Firmware・Packages に分ける。
main の解釈: Base と Packages は全 platform（'*'）、Desktop（desktop・GPU の stack と X11 の group）と Firmware は build の規則の
ある platform に限ってよい。MAC-T001 の検査をそれに合わせる。noct・zedinst（'*' でない Base・Packages）は WS073 が調べる。

main の補足（2026-09-28）: noct（Packages）は interpreter の build が amd64・i386・arm64 だけで、sun4u・x68k に toolchain が無い。
zedinst（Base）は noct を要る PC の disk の installer。どちらも '*' にすると build できない選択を許すので、検査に理由付きの
短い例外（{noct, zedinst}: platform に無い runtime（Noct）を要る）を置く。上の「Base・Packages は '*'」は main の解釈であり、
ユーザーの決定は 4 つの分類だけである。

## 次の手（WS073、未着手）

35 行の group を `base` から新しい `desktop` に移し（dry-run の script で対象を確認済み）、menuconfig の PROGRAM_CATEGORIES を
Base・Desktop（desktop、x11-servers、x11-applications）・Firmware・Packages にし、MAC-T001 の検査を Base・Packages は '*'（例外 {noct, zedinst}）、
Desktop・Firmware は限ってよい、に。menuconfig の host 試験と amd64 desktop の保存された config の program の集合が変わらないことを確かめる。
