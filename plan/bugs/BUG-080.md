# BUG-080: `make menuconfig-host-test` が "MAC-T001: expat is filed under packages/libs, which the menu omits" で失敗する

Bug ID: `BUG-080`
Reproduction: reproduced（host、決定的。db99dda6 でも同じ＝既存）
Disposition: tracking
Date: 2026-09-28
Source: ws035-p098 の確認（desktop の agent）
Owner: 未定

## 観測

`make menuconfig-host-test` が MAC-T001 で失敗: expat の package が `packages/libs` にあり、menu がその分類を出さない。WS035 の変更の前の
main（db99dda6）でも同じ。

## 次の手

menuconfig の package の分類の一覧に `libs` を足すか、expat の置き場を既存の分類に合わせる。menuconfig の host 試験を通す。

## 判断（2026-09-28）

ユーザー:「base, desktop, firmware, packagesに分けましょう。」→ user program を Base・Desktop・Firmware・Packages に分ける。
main の解釈: Base と Packages は全 platform（'*'）、Desktop（desktop・GPU の stack と X11 の group）と Firmware は build の規則の
ある platform に限ってよい。MAC-T001 の検査をそれに合わせる。noct・zedinst（'*' でない Base・Packages）は WS073 が調べる。
