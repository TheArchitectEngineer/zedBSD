# BUG-165: 5330 の DSDT が読み込めない（`ACPI: DSDT Dell Inc stopped at offset 0x1c89b (error 13)`）

Reproduction: reproduced（実機、毎回の起動）
Disposition: tracking（優先度: **最優先**）
Discovery: 2026-10-04 UAT（実機 Latitude 5330、素の起動、image sha256 f03920c3…、main 52e15c0 の CI の構成＋[config-uat.mk](../uat/config-uat.mk)）、[UAT 2026-10-04](../uat.md)
Handling: [WS049](../ws049/ws.md)（kernel の ACPI AML interpreter）の新しい Phase
Evidence: [plan/uat/2026-10-04/](../uat/2026-10-04/)（dmesg・/var/log・session.log・ps・sysctl・Shut Down の間の log）

## 観測

起動の dmesg に `acpi: PCI_Config region of absent function 0:10.6`、`ACPI: DSDT Dell Inc stopped at offset 0x1c89b (error 13)`、`acpi: the DSDT did not load (error 13)`（[dmesg.txt](../uat/2026-10-04/dmesg.txt) の 25〜27 行）。i915 の opregion も `runtime=DISABLED (ACPI_RUNTIME_UNAVAILABLE (no AML …))`。`sysctl` に battery・AC の項目が無い。

影響（候補、共通の根）: Shut Down で電源が切れない（[BUG-119](BUG-119.md)、`\_S5` は DSDT）、タッチパッドの 2 本指・スワイプ・押し込み（[BUG-156](BUG-156.md)・[BUG-167](BUG-167.md)、I2C HID の device は ACPI で見つける）、電源の状態（AC・電池、[BUG-159](BUG-159.md)・ws134-p009）、電源ボタンの event。

次: offset 0x1c89b の AML の op を DSDT の dump（`acpidump` 相当、または dmesg の前後）で特定し、error 13 の意味（`src/drivers/acpi/aml-*.c`）を読む。host の試験で DSDT の bytes を流して再現（実機の DSDT は 5330 から取り出す）。受け入れ: 実機で DSDT が読め、`\_S5` で電源が切れる。

## 原因の分析（2026-10-04 Q1、code を読んで。実機の確認は未実施）

- error 13 は zedBSD の errno で **ENODEV**（`include/uapi/errno.h:34`）。
- DSDT の最上位の term list が PCI の機能 **0:10.6** の PCI_Config の region を読み書きする。5330 ではこの機能が無い（BIOS で無効・隠し）。dmesg の `acpi: PCI_Config region of absent function 0:10.6` は `src/drivers/acpi/acpi-kern.c:946-950` が出し、ENODEV を返す。
- interpreter はその error で table の実行を打ち切る（`src/drivers/acpi/aml-table.c:360-368`）→ DSDT 全体が読まれず、`\_S5`・I2C HID・電池などの定義が一つも登録されない。
- **AML の新しい実装は要らない。** 実在の PCI と ACPICA に合わせ、無い機能の PCI_Config の region は**読みは全ビット 1（0xFF…）、書きは無視**にする（`acpi-kern.c` の数行）。
- 試験: host の AML の試験に、無い機能の PCI_Config の region を読み書きする table を足し、読み込みが最後まで進むこと。実機（5330）で DSDT が読めること、Shut Down で電源が切れること（BUG-119）、タッチパッド（BUG-156・167）・電池（BUG-159）を確かめ直す。DSDT の先で別の所に引っかかる可能性は残る。
