# BUG-333: Pi 4 の USB の touchscreen で 1 本指のスワイプが 2 本指のスワイプとして扱われる

- 状態: reproduced（ユーザーの観察、Pi 4 10.0.30.6、main 5a13204 の kernel と userland）/ scheduled
- 発見: 2026-10-17 ユーザー「1本指のスワイプが2本指スワイプで認識されています。この点を調査できますか。サブエージェントでお願いします。」
- 機器: USB の HID の touchscreen（usb0 device 4、interface 0、contact-count-maximum=10、report 54 byte、10 slots。interface 1 は vendor の report で attach 失敗、interface 2 は mouse の emulation で非公開）。/dev/input/event2 HIDTOUCH Touchscreen。
- 手がかり: dmesg に `hid-input: usb0/port1/device4/interface0 touch: 2 fingers down at once (of 10 slots)`。1 本指で 2 つの contact が down になっている見込み（contact count・tip switch・slot の扱い、hybrid の report mode の扱い）。
- 担当: q1238。
