# BUG-193: 起動の logo の画面の animation が、最初は速く、その後に通常の速さに戻る

Reproduction: reproduced（実機 5330、UAT 2026-10-05 午後）
Disposition: tracking
Discovery: 2026-10-05 午後 UAT（実機 Latitude 5330、image は 12 時の uat-0505c の見込み、sha256 018fa0bd…）
Handling: 起動の logo の描画（boot の splash）。担当は Q1 が割り当てる

## 観測（ユーザー）

「起動ロゴ画面、最初の方はアニメーションのペースが速く、そのあと通常に戻る。kernel tickの設定が影響している？実時間でアニメする必要があると感じました。」

## 期待

animation は実時間（monotonic の時刻）で進み、起動の途中の tick・timer の較正の変化や CPU の負荷に関係なく一定の速さで見える。

## 調べる点

- splash の描画が frame の数か tick（`kernel_ticks`・HAL_TIMER_FREQUENCY）で進んでいるか。起動の初めに timer の較正の前後で tick の周期が変わる（TSC の較正、LAPIC の timer の較正）なら、最初の速さが違う。
- 実時間に替えるには、`hal_rtc_read_counter()` の差か monotonic の clock で経過時間を測り、位相を時間から計算する。
- QEMU で再現するか（較正の前後の差が出るか）。
