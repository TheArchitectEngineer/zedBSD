# BUG-096: worktree の build が共有の LLVM の source に package の patch を当てた（BUG-089 の危険の実害）

Bug ID: `BUG-096`
Reproduction: reproduced（2026-09-28 15:55〜15:57、1 回）
Disposition: resolved（2026-09-28、main が修復）
Date: 2026-09-28
Source: ws075-p015 の agent の報告（main の config での build が「Reversed (or previously applied) patch detected」で失敗）
Owner: main

## 観測

共有の `build/llvm-source` の 41 の file が verified の stamp より新しく、clang の package の patch 4 つ（lldb の zedBSD の process plugin 等）と libcxx の
patch 1 つが当たり、`.orig`・`__pycache__` と package の stamp 2 つ（`.zedbsd-clang-source-*`・`.zedbsd-libcxx-source-*`）ができていた。
BUG-089 の修正（package の source の複写を実の directory にし、共有の tree への書き込みを拒む）を merge する前の Makefile の worktree で、
`build/llvm-source` を共有の tree への symlink にしたまま clang・libcxx の package を build した agent があった（ws075 の BUG-091/092 の agent の
「default の config.mk の build を止めた」の時刻と一致）。共有の `build/llvm`（install 済みの toolchain）は書かれていない。

## 修復（main、ユーザーの承認）

5 つの patch を逆順に `patch -R -p1 --fuzz=0 -E` で外し、`.orig`・`__pycache__`・package の stamp 2 つを消した。`.zedbsd-source-manifest` の
全 file の SHA-256 を `sha256sum -c` で照合して全て一致、file の一覧も manifest と過不足 0（空白を含む path も確認）。

## 再発防止

- BUG-089 の修正（main に merge 済み）。
- AGENTS.md の「禁止と承認」: toolchain は main の許可なしに変えない、subagent の修正可能範囲の明示。
- `plan/tools/toolchain-lock.sh lock`: 共有の toolchain の tree の directory を読み取り専用にした。
