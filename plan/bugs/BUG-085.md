## 観測

実機の run で wltest を kill（wlkill）した client の CLEANUP の直後に、compositor の最後の frame（st1: 194、bisect1: 163）で描画が
止まり、後の場面（egltest）が始まらない。hang・fault・device lost の報告は無い。stencil・multisample の変更の有無に関係なく出た。
BUG-077（close の job の予約の循環の待ち）と同じ系統の可能性がある（未確認）。

## 次の手

再現の率を測り、止まった時の compositor の thread と GPU core の session の状態（予約・fence・待ち）を gdbstub か log で読む。
