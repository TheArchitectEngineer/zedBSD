# BUG-112: zdesktop が xdg_wm_base.destroy を、client に生きている xdg_surface があるだけで protocol error にする

Bug ID: `BUG-112`
Reproduction: reproduced（ws092-p003、QEMU の Venus）
Disposition: tracking
Date: 2026-09-29
Source: ws092-p003 のサブエージェントの報告
Owner: WS035（zdesktop）

## 観測

`userland/desktop/wayland/protocol.c` の ZWL_WM の opcode 0（`xdg_wm_base.destroy`）は、client の中に生きている xdg_surface が 1 つでもあると
protocol error（`defunct_surfaces`）を送り、client の接続を切る。xdg-shell の定義では、対象は destroy される xdg_wm_base の binding から
作った xdg_surface だけである。一つの process の中の library（libkeiland の file chooser）が自分の xdg_wm_base を bind して、使い終わって
destroy すると、app の側の窓が生きているために接続ごと切られた（`ZWL ERROR … object=99`）。

## 回避と直し方

- 回避（ws092-p003）: libkeiland は xdg_wm_base の binding を process に 1 つ持ち続け、ping に答える。
- 直し方: xdg_surface に作った元の xdg_wm_base を記録し、destroy の判定をその binding の xdg_surface だけにする。

## 再検討

WS035 の次の区切り。Qt6・GTK4 の互換（WS096・WS097）など、複数の binding を持つ client を入れる前には直す。
