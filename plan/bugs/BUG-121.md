## 観測

ws075-p025 の作業中、Model viewer の窓の角を drag すると窓が消えた。1 回だけで、原因は見ていない。resize で Model viewer（Vulkan の
swapchain の作り直し）が落ちたのか、compositor が窓を失ったのかは未確認。デモの台本 S11（窓の resize）に関わる。

## 切り分けと直し（2026-09-30、ws099-p011、P5）

[ws099-p011](../ws099/phase011/phase.md)。試験 `plan/ws099/tests/resize-stress.sh`（QEMU）と `resize-hw.sh`（5330 の passthrough）。

- 5330（直しの前、p025 と同じ 10 app の並び、角の drag 20 回）: **6 回**窓が見えなくなった。app は落ちず、compositor も窓を失っていない。
  左上の角の frame の帯（外側 8 px、cursor は resize の矢印）が下の PDF Viewer の title bar の control に重なり、press をその control が取って
  PDF Viewer を前に出し、Model viewer を覆った（`titlebar-shell.c` の `zwl_titlebar_button` が上の窓を見ていなかった）。
- 5330（`ORDER=top`、Model viewer が画面の下まで）: 下の角は Wiseview の下の帯（20 px）に覆われて resize できず、左下の角を上へ drag すると
  Wiseview が開いた（新しい窓の置き場所が下と左右に 12 px しか空けない）。
- 直し: title bar の control の press は、その点で一番上の窓がその窓の時だけ取る。新しい窓は frame の帯が画面の端の帯の外に出るよう置く。
  client を外す時の log `ZWL CLIENT gone client=N reason=` を足した。
- 直しの後: 5330 で 20 回・消失 0（`RESIZE start` 20 回）、QEMU で Model viewer 100 回・wlshm 100 回・消失 0。
- p025 の元の 1 回は log が無く、直接の原因は決められない。
- 別件（main に登録を依頼）: QEMU の Venus で Files・PDF Viewer の上の Model viewer を大きくすると `vkCreateSwapchainKHR` が
  VK_ERROR_DEVICE_LOST で失敗して app が終わる（client が先に切断、compositor は窓を落としていない）。libvulkan・Venus の側。
