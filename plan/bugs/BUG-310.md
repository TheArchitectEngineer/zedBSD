# BUG-310: 第 8 世代 Core（Gen9.5、Let's Note SV7）を素で起動すると、compositor が Vulkan の display の失敗で終わり desktop が出ない

- 状態: reproduced（実機、ユーザーの写真）/ scheduled（2026-10-14 ユーザー「i915の実機の問題です。第8世代Core i5です。P2で直しましょう」、P2）
- 発見: ユーザーの実機の UAT（2026-10-14 夜）。Let's Note SV7（Core i5 第 8 世代、UHD 620、WS229 の Gen9.5、既定 on）を release の候補の image で USB から素に起動し、console で `wayland` を起動。写真: build/review/bug310-sv7-wayland.webp。
- 観察（写真の文字）: `i915: resident shim: context sw_id=2 … engine=rcs0`、`sw_id=3 …` の後に `KWL VULKAN_ERROR operation=display result=-3`、`KWL COMPOSE unavailable errno=5`、`KWL STARTUP step=compose ms=177`、`KWL EXIT frames=0 error=5`。
- 推測（Q1）: Gen9 の i915 は engine と Vulkan だけを動かし display は GOP の framebuffer のまま（WS229 の設計）。compositor は i915 の Vulkan の device を見つけて Vulkan の display（VK_KHR_display 相当）で出そうとし、display の口が無いので失敗し、framebuffer の道に戻らずに終わる。T1 の試験（SV7 の Linux の上の QEMU の passthrough）では guest の画面が QEMU の側だったので見えなかった。
- 回避: 起動の設定に `i915.gen9=off`（手引きの手順）。
- 関連: WS229（i915 Gen9）、BUG-303。
