# BUG-067: devfs の端末の node が chmod を拒む（`mesg n` が ENOTSUP）

Bug ID: `BUG-067`
Reproduction: reproduced（QEMU、amd64 lean guest、salvage の片付けの agent。決定的）
Disposition: tracking
Date: 2026-09-27
Source: ws001-p040（mesg）の guest 試験（`salvage/ws001` の `pinned/guest.sh` の追加の case）
Owner: 未定（WS073 の候補）

## 期待と観測

期待: 端末の所有者が `chmod g-w /dev/console`・`mesg n`（端末の group の書き込みの bit を落とす）を行える。

観測: `mesg n < /dev/console` と `chmod g-w /dev/console` が ENOTSUP で失敗する。devfs の端末の node は `crw-rw-rw-` 固定で、
`src/kern/devfs.c` の属性の変更が EOPNOTSUPP を返す。mesg の実装（ws001-p040、host の pty 試験 9/9）の問題ではない。

## 影響

`mesg`・`write`・`wall` の受信の拒否が効かない。端末の node の所有者・mode を login で変える処理（login・sshd の pty の chown）にも関係しうる（未確認）。

## 次の手

devfs の端末の node に mode（と所有者）の変更を持たせる。直ったら `salvage/ws001` の `plan/ws001/tests/pinned/guest.sh` の
「mesg on the console」の case を戻して ws001-p040 を clear する。
