# BUG-217: 最大化を desktop の session の状態として扱う: 切り替え先の app も最大化し、窓の mode の app から切り替える時は窓にする

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS099・WS142

## 観測（ユーザー）

「1つのアプリが最大化されているとき、WiseviewやAlt+Tabでほかのアプリに切り替えると、切り替え先のアプリがウィンドウモードなら、ウィンドウモードで表示されていますね。これは現在の仕様として妥当なのですが、変更したいです。最大化は「タブレットとして最大化で使う」というユーザの意思だと考えて、デスクトップセッションの状態として捉え、アプリ切り替え時には切り替え先のアプリも最大化したいです。逆もしかりで、ウィンドウモードアプリから最大化アプリに切り替えるときは、ウィンドウ化します。」

## 次（未確認の見込み）

仕様の変更（ユーザーの決定）。WiseView・Alt+Tab・bar の click など全ての app の切り替えで、切り替え元の dock（最大化）の状態を切り替え先に移す。
