## 観測と所在

`less`（`userland/base/less/main.c`）は `more` と共通の pager（`userland/base/common/pager.c`、`pager_main(PAGER_LESS, ...)`）を使い、
Ctrl-F（1 画面進む）と Ctrl-B（1 画面戻る）を扱わない。GNU less と同じく、Ctrl-F は `f`・space、Ctrl-B は `b` と同じ動きにする。
`more` の振る舞い（POSIX）は変えない。

## 修正と確認（2026-09-29、[ws073-p031](../ws073/phase031/phase.md)）

- `userland/base/common/pager.c`: less の style に限り Ctrl-F（0x06）と `f` を space（1 画面進む）、Ctrl-B（0x02）を `b`（1 画面戻る）に読み替える。
  以前の pager に `f` は無かったので GNU less と同じく less に足した。more は変えていない（Ctrl-F・f は more では従来どおり何もしない）。
- `plan/ws073/tests/pager-keys.py`: 修正前 FAIL（less で ^F・^B・f が動かない）、修正後 host と QEMU の guest（`ssh -tt`）で `PAGER-KEYS:PASS`。
- 未実施: 実機、graphical の terminal の中での確認。
