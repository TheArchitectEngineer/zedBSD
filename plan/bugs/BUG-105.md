# BUG-105: 素の 5330（demo-lcd3）で USB マウス（logi M650）が使えない

Bug ID: `BUG-105`
Reproduction: reproduced（ユーザー、素の 5330、demo-lcd3、2026-09-29）
Disposition: tracking
Date: 2026-09-29
Source: ユーザー「demo-lcd3は実機でUSBマウスが認識されませんでした。確認してほしいです。logi M650です。」
Owner: WS073（未割り当て）

## 観測

- M650 を USB で使うときは Logi Bolt の USB 受信機（Logitech、vendor 046d）を経由する。
- 同じ日の demo-lcd2 の起動で main が ssh で読んだ Kei の `lsusb` に Logitech の device は無かった（webcam 0c45:6d1d、指紋 0a5c:5842、
  USB の storage 30de:6545、USB の LAN 0bda:8156 だけ）。そのとき受信機が挿さっていたかは未確認。
- 5330 の Linux（2026-09-29 19 時台）の `lsusb` にも受信機は無い（挿さっていない）。

## 調べること

1. 受信機を 5330 に挿して Linux で `lsusb -v -d 046d:` と HID の report descriptor（`/sys/kernel/debug/hid/*/rdesc` か `usbhid-dump`）を取る。
2. 素の Kei で同じ port に挿して `lsusb` に出るか（列挙の段階か、HID の段階か）。
3. HID の段階なら、取った report descriptor を `src/drivers/usb/usb-hid.c` の parser に host で通す（report ID 付きの report protocol、
   受信機の複数の interface: keyboard・mouse・HID++ の vendor）。
