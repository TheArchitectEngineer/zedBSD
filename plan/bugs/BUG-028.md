# BUG-028: 誰も listen していない loopback ポートへの connect が返らない

Bug ID: `BUG-028`
Reproduction: reproduced
Disposition: open
Date: 2026-09-22
Source: WS032 p009（ターゲット上の lldb）で、終了した lldb-server のポートへ `gdb-remote 127.0.0.1:1234` した lldb が戻らなかったことから観測。
Owner: none（未割当）
Queue: none。

## 期待と観測・影響

`127.0.0.1:1234` で listen するプロセスがいない状態で TCP `connect()` すると、`ECONNREFUSED` で即座に失敗するべきところ、呼び出しが返らない（90 秒以上待っても戻らない）。lldb では `(lldb) gdb-remote 127.0.0.1:1234` の後、ログに "Connecting to connect://127.0.0.1:1234" が出たまま止まる。

loopback の SYN に対して RST が返っていないか、RST を受けても connect を起こしていないと考えられる。

## 次の条件

`src/kern/net` の TCP で、listen ソケットのないポートへの SYN に RST を返すこと、および RST 受信で SYN_SENT の connect を `ECONNREFUSED` で起こすことを確認する。小さな C プログラム（閉じたポートへ `connect()` し、戻り値と errno を出力）で再現できる。
