# BUG-197: 実機 5330 で shutdown しても電源が落ちない

Reproduction: reproduced（実機 5330、UAT 2026-10-05 午後、image uat-0505c = main ee2f8c7）
Disposition: tracking（優先度: 高）
Discovery: 2026-10-05 午後 UAT。ユーザー「シャットダウンは電源が落ちず。」
Handling: WS049（ACPI の S5）。[BUG-195](BUG-195.md) と同じ根の見込み。担当 P1

## 見込みの原因

S5（soft off）に入るには DSDT の `\_S5` の SLP_TYP の値を PM1_CNT に書く（`_PTS` も呼ぶ）。DSDT が読めない（BUG-195、`acpi: attachment failed (error 28)`）と `\_S5` が分からず、電源を落とせない。

## 調べる点

- BUG-195 の直しの後に `\_S5` が引け、`KERN_SYSTEM_POWEROFF` で PM1a/PM1b_CNT に SLP_TYP|SLP_EN を書いて落ちること（host で `\_S5` の値、実機の UAT）。
- DSDT が読めない時の fallback（Intel の PCH の既知の SLP_TYP の値は使わない。失敗を表示して停止のまま、など）を決める。
