# BUG-219: title bar の題と menu（File など）が同じ字で、何が押せるか分からない（menu の項に薄い下線）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS099（title bar）・WS090

## 観測（ユーザー）

「Phoneアプリで、タイトルバーのPhoneというタイトルとFileというメニューでフォントが同じなので、何がクリック可能なのかわからないです。メニューアイテムには薄いアンダーバーをつけるとわかりやすいと思います。」

## 次（未確認の見込み）

title bar の menu の項に薄い下線（全ての app の title bar の menu）。

## 実装（2026-10-06 P2、q798）

- `userland/desktop/wayland/menu-shell.c`: title bar（浮いた窓と dock の時の system bar）の top-level の menu の項の名前の下に、名前の ink の 0.28 の 1 px の線（名前の幅、baseline の 4 px 下、`ITEM_UNDERLINE`）。押せない項は名前と同じく薄い。"..."（overflow）には引かない。全ての app の compositor の menu に効く。
- build: zedBSD・Linux の warning 0、style-check 0。QEMU の撮影は T1（Phone・Files・Terminal の title bar）。
