# BUG-180: 最大化した窓を上部のバーからドラッグで外すと、いったん外れた後に一度最大の大きさに戻ってから小さくなる

Reproduction: reproduced（実機）
Disposition: tracking（優先度: 高）
Discovery: 2026-10-04 夜 ad-hoc UAT-3（実機 Latitude 5330、image `build/uat-3/hdd-image.img` sha256 ada4492e…、main efe846a、[uat.md の uat-3](../uat.md)）
Handling: WS099（compositor の窓の操作）

## 観測

ユーザー「最大化したウィンドウを、スクリーン上部バーからドラッグで外すとき、いっかいスムーズに外れるが、さらにドラッグすると一度最大サイズになってからまだ小さくなる。この問題を修正して。」

## 次

unmaximize の時に client へ送る configure の順（元の大きさ）と、ドラッグ中の位置の更新が、client の古い大きさの buffer（最大のまま）を一度表示している疑い。unmaximize の configure の ack を待ってから元の大きさで描く、または古い buffer を縮めて見せない。 修正は P3（Bug の修正の担当、phase-runner-mid）の Queue で。QEMU の確認は T1、実機は次の UAT。
