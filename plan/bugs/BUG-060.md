# BUG-060: guest の `mkfs -t ufs FILE` が write cached の UFS の mount の上で EBUSY で終わり、その volume の umount と sync も EBUSY

## 観測

format は正しく書かれるが mkfs は EBUSY で終わり、以後その volume の umount と全体の sync が EBUSY を返す（lease が漏れたと見る）。`-o writethru` の mount では起こらない。

## 次の手

ws061-p006 の format の reserve の lease と write cached の関係を調べる。
