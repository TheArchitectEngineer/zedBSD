# BUG-065: 同じ block device を 2 か所に read-write で mount できる（volume を壊す）

Bug ID: `BUG-065`
Reproduction: reproduced（QEMU、WS072 の agent、native の guest image。base の image でも同じで既存）
Disposition: scheduled（WS073、優先度 高: data を壊す）
Date: 2026-09-27
Source: WS072 の agent の guest の操作（main から WS073 へ転送）
Owner: WS073

## 期待と観測

期待: mount 済みの device の 2 度目の mount は EBUSY（少なくともどちらかが書き込み可能なとき）。

観測（root が `/dev/nvme0n1p2` の guest）:

```
mkdir /w; mount -t ufs /dev/nvme0n1p2 /w     # 0 で返る
mount
/dev/nvme0n1p2 on / type ufs (rw)
/dev/nvme0n1p2 on /w type ufs (rw)
```

1 つの volume に独立した UFS の状態（cylinder group の cache、journal）が 2 つでき、volume を壊す。

## 次の手

WS073 の phase で、mount の経路に device の排他を入れる（ws073 の ws.md）。
