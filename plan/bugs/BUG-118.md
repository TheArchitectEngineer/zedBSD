# BUG-118: X client（X terminal）が cursor を空にすると、focus が変わるまで cursor が全画面で隠れる

Bug ID: `BUG-118`
Reproduction: reproduced（5330 の passthrough、2026-09-30）
Disposition: resolved（ws099-p007、2026-09-30）
Date: 2026-09-30
Source: ws075-p024 の途中報告
Owner: WS099（compositor、`userland/desktop/wayland/seat.c` の `cursor_hidden`）

## 観測

X client が cursor を空にすると、keyboard の focus が変わるまで cursor が全画面で隠れたままになる。実機の 5330 でも、X terminal に focus が
ある間は pointer が見えないはず（未確認）。Wayland の cursor は pointer の下の surface ごとに決まるので、X terminal の外では矢印を出すべき。

## 解決（ws099-p007、2026-09-30）

- 原因: cursor の状態は server に 1 つで、keyboard の focus が変わるまで戻らず、pointer が窓の外に出ても client の「隠す」が効いていた。
- 修正: cursor の状態を決めた client を記録し、pointer の下の窓の本体がその client のもの（か popup の grab 中）のときだけ client の cursor を使い、
  他ではデスクトップ・title bar を含め zdesktop の矢印を描く（`cursor.c` の `zwl_cursor_client_shown`、`compose.c`）。
- 確かめ（QEMU の Venus）: `plan/ws099/tests/cursor-owner.sh`（`wlshm --hide-cursor`）: 変更前は FAIL（デスクトップ・title bar でも矢印なし）、
  変更後は PASS。基準 C9 の一覧に入れた。X terminal そのものと実機（5330）は未確認。
