# BUG-322: Pi 4 で browser の headless `--render-gpu` が vkCreateRenderPass で device lost（-4）

- 状態: reproduced（Pi 4 実機、T2、2026-10-15）/ tracking
- 発見: T2 の T1-659（BUG-320 の確かめ）。`/bin/browser --render-gpu …` が `VULKAN reply failed result=-4 ... device lost`・`browser: cannot draw on the GPU: vkCreateRenderPass failed (-4)`、rc 1。dmesg `v3d: command failed opcode=82 error=21`。p238 の前の libbrowser でも同じ。CPU の `--render` は rc 0。windowed の描画（swapchain）は動く（BUG-320）。
- 読み（未確認）: offscreen の render pass（swapchain でない image の attachment）の作りで V3D の kernel の Vulkan が command 82 を失敗させ、device を lost にする。
- 影響: Pi で browser の GPU の描画の自動の試験（headless の PNG）ができない。利用者の窓の描画には影響しない見込み。
- 関連: BUG-320、WS141（Pi の GPU）、WS074。
