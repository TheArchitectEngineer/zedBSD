# BUG-274: `ps -o args` が argv[0] だけを出す（引数が出ない）

- 状態: reproduced（QEMU、2026-10-09 P1 の調べ） / scheduled（直しは main にある（2026-10-11 P2 q935 で確認）。guest の直接の確かめは未実施: T1-489 (b) が安全の判定で止まり、ユーザーの判断で skipped（UAT 待ち）。確かめの script を用意、T1 への依頼は Q1・ユーザーの判断）
- 観察: src/kern/exec.c が process の command に argv[0] だけを写すので、`ps -A -o pid,args` の args に引数が出ない。POSIX の ps の args は「command と引数」。
- 影響: 試験が引数で process を探す所が一致しない。2026-10-09 に 2 つの試験の不具合の根になった（T1-475 の u-guest の `wltest --app-id=u.a`、aatlib の stop_programs の `files --desktop`）。
- Q1 の判断（2026-10-09）: kernel の process の command に引数まで（上限つき）持たせ、ps の args に出す。試験は今の直し（pid で除く）のままでよい。
- 担当: P1（ベータ2 の合間、小さい）。

## 直し（2026-10-09 P1）

- kernel: `struct process` に `arguments[256]`（`include/kern/process.h`）。exec の 3 か所（`process_spawn_from`・`exec_sandbox_start`・`process_exec_file`、`src/kern/exec.c`）で新しい `exec_set_arguments()` が argv を空白 1 つで繋いで入れる（入らない分は切る）。fork は親の line を写す（`src/kern/process.c`）。
- UAPI（追加だけ、`process_info` は変えない）: `struct system_process_arguments`（pid・version・struct_size・reserved・`arguments[KERN_SYSTEM_PROCESS_ARGUMENTS_MAX]` 256）と `KERN_SYSTEM_GET_PROCESS_ARGUMENTS`（`_IOWR('s', 20, …)`。17〜19 は使用済み）。`src/drivers/generic/system-device.c` の `system_get_process_arguments()` は、pid の process の line を返す。setproctitle で title を付けた process は title（BSD の ps の args と同じ）を返し、別の identity の caller には空を返す（GET_PROCESS の command と同じ）。無い pid は ENOENT。
- ps: `args`・`command` は新しい ioctl の line（取れなければ今までの command）、`comm` は今までどおり argv[0]（`userland/base/ps/main.c`）。
- 確認: `make … build/p1-ws177/vmunix build/p1-ws177/bin/ps`（-Werror、成功、warning 0、include check・vmunix check を含む）。QEMU は T1 で（未実施）。

## main の確かめと guest の確かめの用意（2026-10-11 P2、q935）

- main（base ba06b7b40）に直しがあることを読んで確かめた: `include/kern/process.h` の `arguments[256]`、`src/kern/exec.c` の `exec_set_arguments()` の 3 か所の呼び出し、`src/kern/process.c` の fork の写し、`include/uapi/system.h` の `KERN_SYSTEM_GET_PROCESS_ARGUMENTS`、`src/drivers/generic/system-device.c` の `system_get_process_arguments()`、`userland/base/ps/main.c` の `ps_snapshot_arguments()`。読み直しで誤りは見つからなかった（command の 64 byte は 256 の field に収まる、切った line は NUL で終わる、別の identity には空）。
- host: `sh plan/ws001/tests/ps-host-test.sh build/bug274-ps-host` → `ps-host: PASS`（args・-f の command line の case を含む、fake の /dev/system）。
