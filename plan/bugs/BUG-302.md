# BUG-302: emacs（REmacs）で SKK を起こすと辞書が見つからない

- 状態: unknown / scheduled（2026-10-14 Q1 登録、bug-analyzer へ）
- 発見: ユーザーの UAT（2026-10-14）「emacsコマンドでSKKを起動したとき、辞書がみつからなかったです。」
- 期待: `/bin/emacs` で SKK を on にすると、同梱の辞書（`/usr/share/remacs/skkjisyo.dic`、`userland/base/emacs/Makefile` が image に入れる）で変換できる。
- 観察: 辞書が見つからない（文言・環境（image の config・端末）は未確認）。
- 手がかり（Q1、source を読んだだけ）: `editor/skk.noct` の skkInit は `REMACS_SKK_DICT` → `/usr/share/remacs/skkjisyo.dic` → `dict/SKK-JISYO.remacs`（相対）の順。主の辞書は `~/SKK-JISYO.L`。辞書の file は emacs が `ZEDBSD_USER_PROGRAMS` にある時だけ image に入る。`config/current-uat.mk` に emacs は無い。
- 関連: WS129（emacs の取り込み、ベータ2）。
