# BUG-108: unix socket の blocking の connect が backlog の満杯で待たずに EAGAIN（多数の client の一斉の起動で失敗）

Bug ID: `BUG-108`
Reproduction: reproduced（QEMU の Venus の desktop、ws073-p034）
Disposition: tracking
Date: 2026-09-29
Source: ws073-p034 のサブエージェントの報告
Owner: WS073

## 観測

- `src/kern/net/unix-socket.c` の listen は backlog を 16 に clamp し、backlog が満ちると `connect` は blocking でも待たずに EAGAIN を返す
  （Linux の AF_UNIX の blocking の connect は空きを待つ）。
- 40 の Wayland の client（wlshm）を間隔なしで一斉に起こすと `setup errno=5` で失敗した。
- 同じ時に wltest（EGL）の 4 本が `errno=24`（EMFILE）で窓を開けなかった（単独では開ける、原因は未調査）。
- デスクトップの起動の直後に多数の app を開く時に効く。試験は 0.3 s おきで回避していた。
