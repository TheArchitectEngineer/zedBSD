# BUG-194: Terminal を全画面にすると戻る方法が無い。F11 で全画面にも戻すこともできない（compositor が全画面から戻る操作を持っていない）

Reproduction: reproduced（実機 5330、UAT 2026-10-05 午後）
Disposition: resolved（2026-10-05 Q1: P2 b5bdb3f0、T1-188 PASS（QEMU、Terminal が F11 で全画面に入り戻る、compositor が F11 で全画面から戻す）。実機は次の UAT（Fn+F11）。compositor の key の最終の決定はユーザー）
Discovery: 2026-10-05 午後 UAT（実機 Latitude 5330、image は 12 時の uat-0505c の見込み）
Handling: Terminal（app）と compositor（WS099、全画面の扱い）。担当は Q1 が割り当てる

## 観測（ユーザー）

「Terminalは全画面にすると戻るキーがみつからなかった。F11で戻れない。しかも、F11で全画面にもできない。バグです。そもそも全画面はゲーム用の機能で、コンポジタを無効にしてスキャンアウトを占有するものです。全画面から戻るキー操作は、コンポジタが持っておく必要があります。ここはコンポジタのバグにもします。」

## 期待（ユーザーの方針）

- 全画面はゲーム用の機能で、compositor の合成を止めて scanout を占有する物。
- **全画面から戻る key の操作は compositor が持つ**（app に任せない）。app が応答しなくても、利用者は compositor の key で全画面から戻れる。
- F11 で全画面に入る・戻る（少なくとも Terminal で。compositor の側の key で戻れること）。

## 調べる点

- Terminal がどの操作で全画面になったか（menu か、title bar の button か、gesture か）と、Terminal の F11 の扱い（key を受けていない、または処理が無い）。
- compositor の全画面（xdg_toplevel の set_fullscreen、direct scanout）で、compositor が奪う key（例: F11、Super+↑/↓、Esc の長押しなど）の設計。WS099 の窓の操作・WS142 の key の割り当てとの整合。
- 決める key（compositor が全画面から戻す操作）は、ユーザーの確認が要る（案を出す）。

## 調査と修正（2026-10-05、P2 g15、q757）

- Terminal の F11: View > Fullscreen の shortcut（F11、`terminal/menu.c`）は compositor の System Menu が選ぶ（`menu-shell.c` の `zwl_menu_key`、F11 の evdev 87 → keysym 0xffc8 は表にある）。QEMU の上ではこの経路で全画面になるはず（未確認、T1 で見る）。**実機で F11 が効かない理由の推測**: Latitude 5330 の上の列は既定で媒体の key で、F11・F12 の位置は Fn 無しで Home・End を送る（Fn+F11 か Fn Lock（Fn+Esc）で F11）。evdev の記録は採っていないので推測。次の UAT で Fn+F11 を試してもらう。
- 直し:
  1. **compositor**（`wayland/shell.c`、`zwl_glass_key` の中の `fullscreen_leave_key`）: focus の窓が全画面の時、修飾 key 無しの F11 は compositor が取り、`zwl_window_leave_fullscreen` で窓に戻す（app が応じなくても compositor の側で窓として描く）。press と release の両方を app に渡さない。log `ZWL GLASS fullscreen-leave surface= via=f11 error=`。全画面でない窓では F11 は従来どおり menu と app へ。
  2. **Terminal**（`terminal/window.c`）: F11 が app に届いた時（compositor の menu が無い desktop）、shell に escape を送らず全画面を切り替える（log `ZTERM FULLSCREEN key on=`）。
- compositor が全画面から戻す key の案（ユーザーの確認待ち、今は仮に F11）:
  - A. **F11**（今の実装）: 多くの app の慣習と同じ。ただし 5330 のように Fn が要る keyboard がある。
  - B. **Super+↓**: Fn が要らず、Windows の「元に戻す」と同じ方向。app が使うことはまず無い。
  - C. **Esc の長押し（1 秒）**: ゲームの Esc の短押しを妨げず、どの keyboard にもある。
  - D. 画面の上端からのスワイプ（touch・pointer、既存の端のジェスチャーの拡張）。
  - 提案: A と B の両方（または B と C）。
