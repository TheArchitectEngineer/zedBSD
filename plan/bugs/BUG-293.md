# BUG-293: DHCP が失敗して 169.254.x.x（link-local）になった後、`net down en0` などをしても 169.254 の address が外れない

- 状態: unknown（未解析） / tracking
- 発見: 2026-10-12 ユーザー（Pi 4、place23 以降の image）:「net down en0してもなにしても、DHCPの割り当て失敗の169.*.*.*が解除されないバグに遭遇」。
- 関係する source（Q1 の見当）: networkd が DHCP の失敗の後に link-local を割り当てる（`userland/base/networkd/managed-lan.c` の `networkd_lan_link_local`）。`net`（`userland/base/net/main.c:2225` 付近で 169.254.0.0/16 を「自分の address が無い」と扱う）、dhcpc、ifconfig。
- 期待: `net down en0` で address が外れ、`net up`・DHCP の再試行で 169.254 が DHCP の address に置き換わる。
- 観察: 169.254 が残り、解除されない。
- 再現の条件・手順・環境: 未記録（ユーザーに確かめる。Pi 4 の genet（en0）か USB か、DHCP の server の有無）。
- 次: bug-analyzer が source を読んで原因の候補を出す。Pi の SSH が戻ったら networkd の log と ifconfig の出力で確かめる。
