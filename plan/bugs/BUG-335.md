# BUG-335: i915 の Gen12 の MOCS の表が Linux と違う（entry 63 と TGL の表）

- 状態: unknown（実害は観測していない）/ tracking
- 発見: WS252 p001 の設計のレビュー（design-review-1.md M2、design.md 版 3 §2.1、2026-10-19）。
- 中身:
  - entry 63: Linux 6.8.12 の `GEN11_MOCS_ENTRIES` は L3 UC（`gt/intel_mocs.c:259-261`）。zedBSD は 63 の行を持たず、unused の index 2 の値（L3 WB）を入れる（`src/drivers/gpu/i915/intel/mocs-table.inc:12-13`）。全部の Gen12（TGL・ADL-P）に効く。
  - TGL の表: Linux は TGL・RKL に `tgl_mocs_table` を使うが、理由は user の ABI（`intel_mocs.c:530-531`）。zedBSD の TGL は gen12 の表の値。zedBSD の render は uncached の index 3 だけを使い、index 3 は 2 つの表で同じ。
- 影響: 未確認（hardware が index 63・0・1 を自分で使うかを確かめていない）。
- 直すなら: 5330（ADL-P）の T1 の回帰と、5320（TGL）のユーザーの試験の一覧が要る。
- 関係: [WS252](../ws252/ws.md)（design.md §2.1、D4 を WS の外へ出した）。
- 次: 担当・時期は未定。
