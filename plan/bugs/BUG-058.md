Disposition: tracking

Source: ws069-p010（q489-i01）の実機の run2（`build/ws069-p010-hw2/`）
Owner: 未定

## 期待と観測

期待: Gears が描かれて回る。観測: `ZGEARS START`（glXMakeCurrent の後）の後に何も出ず（CHECK・FRAME・STALL・`Xlib: send failed` も無い）、
Gears の窓は黒いまま、X terminal の撮影の時には窓が消えている（client が終わって X server が窓を閉じた）。executor の log に zgears の
pipeline（vs 7568 byte）の compile が無い（最初の描画の前）。X server の止まった client の報告も無い。

## 疑い

START の後、frame の loop の前（display list の作成 `gears_setup`）で落ちた（SIGSEGV 等）か exit した。watchdog は loop の中だけ。
kernel の log に user の fault の行は残っていない（dmesg の ring は最新だけ）。

## 再調査の条件

再発したとき。zgears に setup の段の印と、SIGSEGV の handler（async-signal-safe に段と address を出す）を足し、実機の run で確かめる。

## 再試験（2026-09-28、ws075-p016 の実機の run、WS075 の i915 の subagent）

デモの image（`plan/ws075/demo/build-demo-image.sh build/h4-hold2 passthrough`、main の kernel + ws075-p015 の timer の修正 + ws075-p016 の
hold）の session（HDMI 1920x1280）で、App Home の Gears（`keiland-x11 /bin/zgears --frames=0`）を 6 回起動し（毎回 title bar の × で閉じる）、
起動の約 9 秒後の scanout の画面で窓の中の赤・緑・青の画素を数えた: **6 回とも 3 つの歯車が描かれて回った**（赤 3828〜3861・緑 869〜907・
青 756〜774 の標本、`build/ws075-shots/ws075-bug058-gears-from-app-home.png`）。kernel の log に zgears の pipeline（vs 7568 byte）の
compile がある。再現せず（6 回、実機の passthrough）。再調査の条件は変えない（再発したとき、setup の段の印と SIGSEGV の handler）。

## 2026-09-29 追記（main）

ws075-p009 で、render engine の context の上限（`worker.c` の `I915_WORKER_CONTEXTS` 8）により、9 つ目の GPU の node を開いた app が窓を出さずに終わる形を確実に起こした（Gears・Browser）。上限を 32 にした後、App Home の 8 app が全て開いた（passthrough）。BUG-058 はこの形だった可能性がある（推測、素の 5330 で確かめる）。

2 回目（m-guard2）と手の操作の run では出た。間欠の同じ形と見ている（推測、原因は未特定）。
