Bug ID: `BUG-077`
Reproduction: reproduced（i915 実機 Latitude 5330、zdesktop-files の場面で Files まで進んだ 4 回（hw-2〜hw-5）中 2 回（hw-3・hw-4）、WS075 の agent。間欠）

## 観測

5330 の log: `i915: resident shim: XXX unimplemented path: engine_recover(engine 0, error 5)`、`device fault 13`。続いて zwl が
`ZWL VULKAN_ERROR operation=acquire result=-4`、`ZWL FAILED site=compose_draw errno=5`、`ZWL EXIT ... error=5 cleanup_failed=1`。画面は止まったまま。
hw-4 では Home を描き Files（client=2）が接続する途中。run 2 は hang せず、Files の glass・タブが正しく描けた（実機でタブの開閉・切り替え・Wiseview の検査 PASS）。

### 詳細（WS075 の agent、2026-09-28）

| run | 日時 | 結果 |
| --- | --- | --- |
| hw-2 | 2026-09-27 | hang なし（Files が開き、タブ・Wiseview の検査 PASS。dock は場面の座標の誤り） |
| hw-3 | 2026-09-27（main 66c5f08a の merge の前） | hang。compositor の log は frame 209 で途切れ（UFS の write cache で後ろが失われた）、8 枚の shot はすべて同じ画面で pointer も動かない |
| hw-4 | 2026-09-28（merge の後） | hang。Home を開いた後（frame 199〜204 は Home を描く）、Files の icon の click で client=2 が接続した直後 |
| hw-5 | 2026-09-28 | hang なし、場面 9/9 PASS |

- hw-4 の順: `ZWL HOME launch`（Files）→ `ZWL CLIENT client=2` → `ZWL VULKAN_ERROR operation=acquire result=-4`（VK_ERROR_DEVICE_LOST）→
  `ZWL FAILED site=compose_draw errno=5`。kernel 側は `i915: perf: 12188 ms: ... 320 submits` の窓（普段の 5 s の窓が 12 s に延びた = 7 s
  ほど submit が返らなかった）の後に `engine_recover(engine 0, error 5)`・`device fault 13`・`object destroyed while bound; retained`・
  `session 5 closed while quarantined`。以後の ioctl は error 13。
- hang の直前に GPU で動くのは compositor（zwl、Vulkan）の描画だけ（Files は wl_shm の client で、この時点では窓を map していない）。
  使う kernel は executor の compile した 3 つの pipeline（vs 816/fs 304 が 2 つ、vs 1088/fs 6112 の glass）と fill・copy の transfer kernel。

  hw-5-pass の run.log・result.json）、画面 `build/ws031-shots/ws075-bug077-20260928-hw4-sheet.png`。
