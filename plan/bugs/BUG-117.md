Disposition: scheduled（ws075-p025）

## 観測

- 10 app を開く途中（Model viewer を開いた辺り、p023 の実験では X terminal の後）に compositor の描画が止まる。
- kernel log: `i915: vk: draw refused: set 0 binding 0 has no image view and sampler` → `draw 99652 failed` → command buffer が止まる → lease の解放 →

descriptor の追跡の誤り。
