## 観測

GNU の truncate は無い file を作る（-c で作らない）。mount の `-o rw` は既定と同じなので受けるべき。

## 次の手

utility の修正（WS001 か WS045 の続き）。

## 解決（2026-09-27、ws073-p004）

truncate は `[-c] -s size` で無い file を作る（`-c` で作らない）。mount の `-o` は `rw`・`defaults`・comma の並びを受ける。
