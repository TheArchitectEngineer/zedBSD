## 観測

BUG-091 の修正を含む kernel（main 06abe378）の egltest6 の capture の image で、compositor が始まらなかった。kernel の log は
`resident: GPU node published; serving` で終わり、guest の disk に zdesktop 等の log が無い。約 180 秒後の gdbstub: 4 つの CPU が全て
`sched_idle`、kernel の tick は進む、`next_pid` は 6。service の連鎖の最初の `sleep 45`（vkwait1）が終わらなかったか、init が終わりを見なかった。
**最初の gdb の attach（数秒の VM の停止）がその `sleep 45` の間にあった**ので、attach が原因の可能性を否定できない。

## 次の手

gdb を stall の印の前に attach しない、きれいな run（`plan/ws075/tests/bug085-hw.sh`）を 5 回以上。再び出れば、sleep の timer（BUG-091 で
`kern_usleep_range` を irqsave にした変更を含む）と init の子の回収を調べる。証拠: `build/ws075-b085-evidence/e6-1/`。
