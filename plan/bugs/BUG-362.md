# BUG-362: 共有の shader の frontend が SPIR-V の NoContraction（GLSL の precise）を受けず、precise を含む shader が compile されない

- 状態: open（2026-10-30 Q1 が登録）
- 発見: 2026-10-30 P5（q1693-i01、WS291 の nvrtx の FFMA の融合を調べた時、source の読み）。
- 場所: `src/drivers/gpu/compiler/spirv.c` が NoContraction を「decoration that is not interpreted」として module ごと拒否する。frontend は decoration を IR に運ばない。
- 影響: GLSL の `precise`（SPIR-V の NoContraction）を使う shader は、共有の frontend を使う全ての GPU の executor（nvrtx・mali など）で compile に失敗する見込み（未確かめ）。
- 直す方針: frontend が NoContraction を受け、IR の命令に「融合しない」印を運ぶ。各 backend はその印のある演算を FMA に融合しない（nvrtx は 374eb20c3 で module に NoContraction があれば融合を全部止める暫定の扱い）。
