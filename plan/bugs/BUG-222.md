# BUG-222: ue0 の SCP が約 950 KB/s（約 10 Mbps）。link の速度を Settings に出し、RTL8822BU（実は USB の LAN の device）が 10 Mbps の mode になっていないか確かめる

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS033（USB LAN）・WS089（Settings の Network）

## 観測（ユーザー）

「SCPで他のPCからファイルを送ったところ、ue0の接続で、950KB/s (kilo byte per sec)しか出なかったです。10Mbps程度の計算ですね。リンクアップ速度をSettingsに表示するとともに、10Mbpsになっていないか（複数あるRTL8822BUのモードのうち10Mbpsのものになっていないか）を確かめてほしいです。」

## 次（未確認の見込み）

ue0 の driver（CDC NCM/ECM、RTL8156 など）の link の速度の読み取りと表示。10 Mbps に落ちているなら原因（auto-negotiation・mode の選択）。速度の律速が link でなく driver の転送（USB の bulk の数・NCM の集約・TCP の窓）の可能性も測る。注: RTL8822BU は WiFi の chip、ue0 は USB の有線 LAN（ユーザーに確かめる）。

## 2026-10-06 ユーザーの見込み

「USB LANはNCM, ECMが両方あるときの選択の問題かもしれないので、記録しておいてください。」→ USB の LAN の device が CDC NCM と CDC ECM の両方の configuration・interface を出す時、zedBSD が遅い方（ECM、または NCM の集約の無い使い方）を選んでいる見込み。確かめ: どちらの driver（usb-cdc-ncm・usb-cdc-ecm）が付いたか、configuration の選択の規則、NCM の NTB の大きさ。直し: NCM があれば NCM を選ぶ。link の速度の表示（Settings）も合わせて。
