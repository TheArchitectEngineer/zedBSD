# BUG-069: pty の master の read・slave の write が waitq_sleep の EAGAIN を失敗として返す

Bug ID: `BUG-069`
Reproduction: reproduced（QEMU、amd64、`plan/ws073/tests/pty-backpressure.c` で 100 回中 3〜9 回）
Disposition: resolved（2026-09-27、ws073-p008）
Date: 2026-09-27
Source: ws073-p007（BUG-068 の確認の console の `POSIX-R2.ELF` の 5 回目が pty の back-pressure の試験で止まった）
Owner: WS073

## 期待と観測

期待: blocking の `write(slave, buf, 6000)` は全てを書き、blocking の `read(master)` は data が来るまで待つ。

観測: 子の write が途中で返り（`POSIX-R2.ELF` の子は exit 42）、親の master の read が `EAGAIN` で返る。`POSIX-R2.ELF` は残りの byte を待って
master の read で永久に止まった（gdbstub で main の thread が `pty_master_read` の `waitq_sleep`、子は exit 42 の zombie）。

## 原因

`waitq_sleep(..., WAITQ_INTERRUPTIBLE)` は signal を調べる間に条件の lock を外し、その間の wakeup を `EAGAIN` で知らせる（「条件を見直せ」）。
`src/kern/tty.c` の `pty_master_read()`・`pty_output_bytes()`（slave の write）・端末の canonical と raw の read の 4 か所がそれを失敗として返していた。
同じ file の他の 2 か所と BUG-057（socket）は既に再試行にしていた。

## 影響

pty（SSH・端末の emulator・zdesktop の terminal）と console の端末で、読み書きが稀に EAGAIN や途中の count で返る。shell の read の失敗や出力の欠けになりうる。
`POSIX-R2.ELF` の console の 5 回連続 status 0（BUG-046 の受け入れ）を塞ぐ。

## 次の手

ws073-p008: 4 か所で EAGAIN を再試行にし、`pty-backpressure` の 200 回と console の `POSIX-R2.ELF` 5 回で確かめる。

## 解決（2026-09-27、ws073-p008）

`src/kern/tty.c` の 4 か所で EAGAIN を再試行にした。`plan/ws073/tests/pty-backpressure.c` 0/200 失敗（修正前 3/50・9/100）、console の
`POSIX-R2.ELF` 10 回続けて status 0。他の file の interruptible な `waitq_sleep` の呼び出しは全て見て、同じ誤りは無かった。
[ws073-p008](../ws073/phase008/phase.md)。
