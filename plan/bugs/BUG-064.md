# BUG-064: libwayland の client が flush の EPIPE を致命的にし、compositor が接続を閉じる直前に送った protocol error を失う

Bug ID: `BUG-064`
Reproduction: reproduced（QEMU、menu-p002 が約 5 回に 1 回 FAIL）
Disposition: resolved（ws070-p005、2026-09-27）
Date: 2026-09-27
Source: ws070-p005（WS035 の agent）
Owner: WS070

## 観測と修正

`userland/desktop/libwayland/client.c` は flush の EPIPE を致命的な誤りとして扱い、compositor が接続を閉じる直前に送った protocol error の
event を読まずに終わった（menu-p002 の error の試験が間欠的に FAIL）。upstream の libwayland と同じく flush の EPIPE を無視して、残りの
event を読むようにした。menu-p002 を 8 回と menu-probe を 60 回、PASS。
