# BUG-208: 最大化（dock）中の Terminal で F11 を押すと bar が消えるだけで窓の content の領域が変わらない

Reproduction: reproduced（ユーザー、Windows の QEMU（Venus）で uat-0505g、2026-10-05 夜 UAT）
Disposition: tracking
Discovery: 2026-10-05 夜 ユーザーの UAT のコメント
Handling: WS099（compositor）・BUG-194（Terminal の全画面と F11・Super+↓）の続き

## 観測

ユーザー「ターミナルアプリでウィンドウ最大化（ドック）中にF11を押すと、画面上部のバーが消えるだけで、ウィンドウのコンテント領域が変わらない。バーの部分はデスクトップが見える。」

## 次（未確認の見込み）

docked の窓が fullscreen に入る時、compositor が bar を隠すが、窓に全画面の大きさの configure を送らない（または docked の geometry が fullscreen より優先される）。BUG-194 の試験（bug194-guest.sh）は浮いた窓で F11 を確かめていて、dock の中からの F11 を含まない。dock → fullscreen → 戻ると dock に戻ること、を試験に足す。
