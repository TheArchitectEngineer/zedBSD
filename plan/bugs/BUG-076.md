# BUG-076: FAT で file を約 250 個より多く作ると空きがあっても ENOSPC

Bug ID: `BUG-076`
Reproduction: reproduced（QEMU、ESP と 512 B・4 KiB cluster の試験の FAT、252 個目で、WS073 の agent）
Disposition: scheduled（ws073-p016、BUG-074 と一緒に）
Date: 2026-09-27
Source: ws073-p016
Owner: WS073

## 期待と観測

期待: 空きのある FAT で file を多数作れる。観測: ほぼ空の volume でも 252 個目の作成が ENOSPC。

## 原因（agent）

`fat.c` が全 FAT mount で共有する固定の 256 個の inode の pool（`FAT_INODE_MAX`）を持ち、汎用の inode cache が参照の無い clean な FAT の
inode を持ったまま、`fat_alloc_inode()` が NULL を返すと `inode_storage_take()` が追い出さずに諦める。BUG-029（tmpfs、ws073-p013）と同じ型。

## 次の手

ws073-p016: filesystem の storage が満ちたら、その型の clean で cache だけの inode を追い出して再試行（`src/kern/inode.c`）。
