# BUG-251: Ctrl+Shift を押したまま起動すると内蔵 keyboard（PS/2）の割り込みが来ず使えない（5330・5320）

- 状態: reproduced（実機 5330・5320、ユーザー 2026-10-07） / scheduled（P2、BUG-250 の後）
- 発見: 2026-10-07 ユーザー「キーボードの割り込みがうまくいかない起動になることがあります。その場合は内蔵キーボードが使えないです。5320でもありました。Ctrl+Shiftで起動するとそうなるように見えます。」

## 疑い（Q1、未確認）

- WS174 の起動の key（Ctrl で kernel の message、Shift で console の login）を押したまま起動すると、i8042 の output buffer に scancode が残ったまま keyboard の IRQ1（edge）が有効になり、以後割り込みが来ない（8042 の古典的な詰まり）。IRQ を有効にした後に output buffer を読んで空にする（status 0x64 の OBF を見て 0x60 を読む）か、初期化の時に flush する。
- src/drivers の i8042（PS/2）の初期化と、WS174 の起動の key の読み方（firmware の BIOS の key の状態か、kernel の早い段階の poll か）を確かめる。

## 次

- 原因を特定して直す。5330 で Ctrl+Shift を押したまま起動しても keyboard が効くこと（ユーザー）。
