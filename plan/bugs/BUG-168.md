# BUG-168: 起動の後に挿した USB の有線 LAN（ue0）が up しない

Reproduction: reproduced（実機）
Disposition: tracking（優先度: 高）
Discovery: 2026-10-04 UAT（実機 Latitude 5330、素の起動、image sha256 f03920c3…、main 52e15c0 の CI の構成＋[config-uat.mk](../uat/config-uat.mk)）、[UAT 2026-10-04](../uat.md)

Evidence: [plan/uat/2026-10-04/](../uat/2026-10-04/)（dmesg・/var/log・session.log・ps・sysctl・Shut Down の間の log）

## 観測

C7: 起動の後に USB LAN（RTL8156）を挿すと ue0 は down のまま。WiFi を off にしても down のまま。起動の時から挿しておくと up して DHCP（10.0.30.3）。hotplug の時に networkd が interface を up・DHCP しない疑い。

次: networkd の device の追加の通知（route socket の RTM_IFANNOUNCE 相当）と自動の up の道を読む。QEMU で usb-net を後から device_add して再現できるか試す。
