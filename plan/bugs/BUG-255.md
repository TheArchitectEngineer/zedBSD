# BUG-255: 蓋を閉じると HDMI へ移るが、蓋が閉じている間 HDMI に 1 frame も出ない（5330）

- 状態: reproduced（実機 5330、2026-10-07 ユーザー「5330でHDMI出力が蓋を閉じても有効になりませんでした。」） / scheduled（P2、優先）
- 証拠: [kernel-5330.log](BUG-255/kernel-5330.log)・[session-5330.log](BUG-255/session-5330.log)（kernel は P2 の build/bug250 の cksum 2877465438、compositor は main の cksum 184482127）

## 観察（Q1、SSH）

- 蓋の事象は届く（BUG-253 の直しが効いた）: kernel `acpi: lid events on GPE 0x18`、session `KWL EVENT lid closed`。
- compositor は HDMI へ切り替えた: `KWL OUTPUT open width=1920 height=1280`、`KWL OUTPUT resized width=1920 height=1280`、`KWL OUTPUT switch name=...:hdmi:B`、`KWL LID external: the desktop moved to the external display`。
- kernel も付け替えた: `i915: resident display: the output moves to connector 1 (HDMI, Keiland's claim)`、`lease 2 claimed`。しかし `lease 2 released after 0 frame(s)`、HDMI の modeset（preflight・picture up）の行が無い。蓋を開けると `KWL OUTPUT switch name=...:edp:A`、`the output moves to connector 0 (eDP panel)`、`lease 3` で panel に戻る。
- 疑い（未確認）: ws052-p012 の sleep.c・shell.c の「蓋が閉じている（または眠る要求の）間は frame を出さない」判断が、外部へ移った後も効いて、HDMI に最初の present を出さない（i915 は最初の present で点けるので、消えたまま）。

## 次

- compositor の frame を出さない条件を、外部の出力に出している時は蓋が閉じていても描くように直す。5330 で HDMI をつないで蓋を閉じ、HDMI に desktop が出る（ユーザー）。
