# BUG-159: バッテリー駆動で描画が 5 fps ほどに落ち、電池切れで警告なく落ちる

Reproduction: reproduced（S1（2026-10-03、Latitude 5330、素の USB 起動、ユーザー、[結果](../ws133/s1-results.md)））
Disposition: tracking（WS075（i915）、電源の管理（WS050〜052・WS132））
Discovery: 安定版 S1 の実機試験（[WS133](../ws133/ws.md)）

省電力に入ったのか GPU が遅くなり cursor の描画が 5 fps ほど。その後バッテリーが切れて落ちた。i915 の周波数（RPS）の制御が AC の抜去・低電池に追いつかない見込み。低電池の警告と安全な停止は電源の管理の WS の範囲。実機が要る。

## 2026-10-04 UAT（実機、[UAT 2026-10-04](../uat.md)、証拠 [uat-2026-10-04](../uat/2026-10-04/)）

**再現せず（実機）**: AC を抜いた直後の System Monitor の fps は 21.5・14.4・22.4（AC の時 21）。ただし `sysctl` に battery・AC の項目が無く（[BUG-165](BUG-165.md)、DSDT が読めない）、OS は電源の状態を知らない。BUG-165 の後に再確認。
