# BUG-111: PDF Viewer で key の repeat が dispatch の前に発火し、矢印等が 2 回効くことがある

Bug ID: `BUG-111`
Reproduction: 未確認（ws091-p002 で imageview の同じ型の作りで起き、直した）
Disposition: tracking
Date: 2026-09-29
Source: ws091-p002 のサブエージェントの報告
Owner: WS079（PDF Viewer）

## 観測

imageview は PDF Viewer の型を写して作った。key の repeat を event の dispatch の前に発火させる作りのため、重い処理で main loop が止まっている間に、
key の release を読む前に repeat が発火し、矢印や Home が 2 回効いた。imageview は repeat を dispatch の後だけにし、切り替えの key は repeat
しないようにして直した（ws091-p002）。PDF Viewer（`userland/desktop/pdfviewer/`）も同じ作りなので、同じ症状が出うる（未確認）。Notes 等、
同じ型の他の app も確かめる。
