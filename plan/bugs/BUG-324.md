# BUG-324: RTX 2070（nvrtx）で cursor が 60 fps で動かない

- 状態: reproduced（実機、ユーザー）/ tracking（記録だけ、2026-10-15 ユーザー「BUGとして記録だけでいいのですが」）
- 発見: 2026-10-15 夜 ユーザー「カーソルが60fpsで動いていなかったので、planeを分ける実装がまだなのかなと思いました。」（RTX 機、BUG-323 と同じ起動）。
- Q1 の読み（未解析）: nvrtx は起動の log で `gpu-device ok: cursor plane 64x64` を出し、hardware の cursor の plane は持っている。cursor の移動が別の plane の位置の更新（cursor の PIO channel）でなく、画面の再描画や present の流れに乗っている、または位置の更新が frame に 1 回より遅い見込み。
- 関連: [BUG-323](BUG-323.md)、WS037（nvrtx）、WS241（RTX の描画の速さ）。
- 次: nvrtx の作業を再開する時に、compositor の cursor の位置の更新がどの道で nvrtx に届くか（cursor の plane か、合成か）を確かめる。
