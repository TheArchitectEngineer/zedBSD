# BUG-290: Raspberry Pi 4 で Settings の窓を undock（dock の後の double click）すると Settings が必ず落ちる

- 状態: reproduced（Pi 4 の実機、ユーザー「Undockすると100%落ちるようです。」） / tracking（P3 が調べ中）
- 発見: 2026-10-12 ユーザー、WS141 p013 の測定の時。
- 観察: Settings の窓を dock（最大化、1904x1020 への resize は成功）の後、double click で undock（1180x800 への resize）すると、`ZSETTINGS FAILED operation=kl_window_present_resize result=-3` の後に client が切れる。-3 は Settings の present.c が libkeiland の EIO を `VK_ERROR_INITIALIZATION_FAILED` に読み替えた値。
- 切り分け: libvulkan を lazy map（P3 の 3b0d9db5c）の前の main 8eb7c81 の物に戻しても落ちる（ユーザー「やはり落ちました。」）→ lazy map のせいではない。compositor は 0d7bbc1ed（P3 の damage の直し）、kernel は main 8eb7c81。
- 次: libkeiland の resize（vkDeviceWaitIdle・swapchain の作り直し・target・canvas の vkAllocateMemory/vkMapMemory）のどこが EIO かを log で特定。bcm2711 の resource の確保・memory の上限。i915・Venus での再現は T1-547。
