# BUG-090: libc の qsort が二次の時間（1 byte ずつ交換する挿入の sort）

Bug ID: `BUG-090`
Reproduction: reproduced（ws079-p006、guest で密な page の描画が 351 ms。rasterizer を自前の merge sort にして 11 ms）
Disposition: tracking
Date: 2026-09-28
Source: ws079-p006（PDF Viewer の agent）
Owner: 未定（WS073 の候補）

## 観測

`src/libc/stdlib-extra.c` の `qsort` は byte ずつ swap する挿入の sort で、要素の数の二乗の時間がかかる。libpdf の reader の xref の sort、
PDF Viewer の file の chooser、glob 等が使う。

## 次の手

O(n log n) の sort（例: introsort か、安定を要らないので heapsort と挿入の組み合わせ）に替え、要素の大きさに応じた swap（word 単位）にする。
libc の既存の試験と大きな配列の試験で確かめる。
