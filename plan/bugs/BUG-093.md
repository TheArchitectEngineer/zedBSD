# BUG-093: Noct の source の stamp が patch の mtime に依り、新しい worktree で make toolchain が止まる

Bug ID: `BUG-093`
Reproduction: reproduced（2026-09-28、BUG-089 の agent の worktree）
Disposition: tracking
Date: 2026-09-28
Source: ws073-p027（BUG-089）
Owner: 未定（WS073 の候補）

## 観測

`userland/base/noct/Makefile` の `$(NOCT_HOST_SOURCE_STAMP): $(ZEDBSD_NOCT_PATCHES)` が patch の mtime に依るため、checkout で patch が新しくなった
worktree では `make toolchain` が「Noct: refusing to replace existing source tree: build/NoctLang」で止まる。拒むだけなので共有の tree は書かれない。
回避: worktree の Noct の patch の mtime を main に合わせる。

## 次の手

BUG-089 の LLVM と同じく、patch の SHA-256 を Noct の identity に入れて中身で判定する（identity の形式の移行が要る）。
