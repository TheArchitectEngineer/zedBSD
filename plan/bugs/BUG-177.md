## 観測

ユーザー「Filesの検索バーで日本語IMEが使えない。」

## 次

Files の検索欄が text-input（zwp_text_input_v3）を有効にしていないか、IME の切り替え・preedit の表示が検索欄に届いていない疑い。他の app（Text Editor など）で IME が使えるかと比べる。 修正は P3（Bug の修正の担当、phase-runner-mid）の Queue で。QEMU の確認は T1、実機は次の UAT。

## 原因と修正（2026-10-05 P1 generation17 / q700 の続き、夜の自律の規則で Bug へ）

- 原因: Files の検索欄（と ws127-p010 の path の欄）は Files の text-input ではなく、compositor が描いて編集する title bar の text field（`titlebar-shell.c` の `shell_field`、WS070 の CONTROLS）。compositor の IME（`input-method.c`）は client の `zwp_text_input_v3` だけを serve し、compositor 自身の欄は serve していなかった。欄の key は IME の grab より前の `zwl_titlebar_key` が US の配列の文字だけを入れていた。
- 修正（compositor だけ、protocol と Files は変えない）:
  - `input-method.c`: compositor の欄を表す text input の記録 `ime_field`（object 無し、surface はその窓、状態は欄から毎回読む）。serve する text input の選び方を `ime_current`（欄が keyboard を持てば欄、無ければ今まで通り client の物）にし、IME が作った preedit・commit・削除を `ime_deliver` で欄（`zwl_titlebar_field_input`）か client に配る。IME の virtual keyboard から戻った key（IME が使わない key）は欄へ（`zwl_titlebar_key`）。`zwl_ime_field_changed`（欄の始まり・終わり・text と cursor の変化で IME に状態を送る、候補の窓の位置も）、`zwl_ime_field_key`（欄が serve されている間、IME の grab を欄の key の処理より先に）。log `ZWL IME activate field client=… surface=…`。
  - `titlebar-shell.c`: 欄の `preedit`（cursor の所に下線付きで描く、text には含めない）、`zwl_titlebar_field_surface`・`zwl_titlebar_field_state`（text・cursor・anchor・窓に対する欄の箱）・`zwl_titlebar_field_input`（周りの削除、commit を選択の所に入れる、preedit。text が変われば client に `text_changed`）。欄の focus・終わり・変化・cursor の移動で IME に知らせる。log `ZWL TITLEBAR ime commit=… preedit=… text=…`。
  - `seat.c`: 鍵の経路で `zwl_ime_field_key` を `zwl_titlebar_key` の前に。
- 同じ欄なので ws127-p010 の範囲 3（path の欄の IME）もこれで入る。
- 確認: zedBSD の compositor・Linux の Keiland の build warning 0、境界 PASS、style-check は変えた所に指摘 0（input-method.c・titlebar-shell.c の既存の指摘の数は同じ）。
- QEMU の試験: `plan/ws127/tests/bug177-guest.sh BUILD`（IME の image `plan/ws095/tests/build-ime-image.sh`、`ime-guest.sh start`。titlebar-probe の検索欄を click → `ZWL IME activate field`、direct で ab、Alt+Space で日本語、kanji の preedit かんじ → Space で 漢字 → Enter で欄に `ab漢字`、もう一度 Enter で done、deactivate。preedit.png）。T1 に依頼（Q1 経由）。実機は次の UAT（Files の検索欄で日本語）。
- 範囲外で残す: 画面の鍵盤（OSK、`keyboard.c`）が compositor の欄に日本語を入れるのは別（OSK は今も client の text-input だけを見る）。
