## Notes

- **zedbsd**: The zlib license asks for no notice in binaries; the image still carries the project's license as the list's first entry.
- **musl-regex**: src/libc/regex/LICENSE has TRE's BSD-2-Clause text but only names musl's MIT license; it needs musl's MIT text added, and the libc package does not install it.
- **i915-intel**: The kernel carries Intel MIT code; the image has no notice for it yet.
- **khronos-headers**: Each header carries its own license text, which travels with it into the development root filesystem.
- **libvulkan-registry**: opcodes.h carries virglrenderer's MIT declarations; LICENSE-PROTOCOL is in the tree but the libvulkan package does not install it.
- **noct**: Zlib asks for no notice in binaries. The clang resource headers in its tree are not installed.
- **remacs**: A GPL component in the image. 2026-10-04 Q1 raised it to the user; the user decides (relicense by the copyright holder, ship with the GPL text and source offer, or leave it out).
- **ime-dict-ja**: Under the project's license file (ws095 D1).
