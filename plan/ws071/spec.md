## 1. 概要

zedBSD File Manager は、ローカルファイル、ユーザーディレクトリ、クラウドストレージ、最近使った項目、共有項目などを統合的に扱うための
GUIファイルマネージャである。

操作感は Finder に近い、

* 左側ナビゲーション
* 上部ツールバー
* パンくずナビゲーション
* アイコン / リスト表示
* プレビュー
* タグ
* 最近のファイル

を基本とする。

一方で見た目はzedBSDのシステムUIに合わせ、

* 明るいすりガラス
* 大きめの角丸
* 浮遊するタイトルバー
* シンプルな操作ボタン
* system-owned menuとの統合

を採用する。

## 2. ウィンドウ構成

通常ウィンドウ時は、以下の2層構造とする。

```
Floating Title / Toolbar
────────────────────────
Main File Manager Body
```

上部ツールバーは本文から少し離して浮かせる。
最大化時はツールバーをシステムメニューバーへ統合可能とする。

## 3. 上部ツールバー

ツールバーには以下を配置する。
左から、

* 戻る
* 進む
* ホーム
* パンくず
* 検索
* 表示切替
* 並べ替え / 表示オプション
* ウィンドウ操作

例:

```
‹  ›   ⌂   > ホーム        [ ファイルを検索… ]   ▦  ≡    — □ ×
```

## 4. 戻る / 進む

ブラウザと同様の履歴型ナビゲーションとする。

* 戻る → 直前に表示していた場所
* 進む → 戻る前にいた場所

ディレクトリ階層とは独立した履歴として管理する。
長押しまたは右クリックで履歴一覧を表示可能としてもよい。

## 5. ホーム

ホームボタンはユーザーのホーム画面へ移動する。
ホーム画面では、

* よく使うフォルダ
* 最近のファイル
* プロジェクト
* ピクチャ
* ミュージック
* ムービー

などをカード形式で表示する。
現在のモックアップのように、単純なディレクトリ一覧ではなくダッシュボード的なホームとする。

## 6. パンくずナビゲーション

現在位置を、

```
ホーム > プロジェクト > zedBSD > src
```

のように表示する。
各階層はクリック可能。
幅が不足した場合は、

```
… > zedBSD > src
```

のように省略する。

## 7. 検索

検索欄はツールバー中央〜右側に配置する。
検索対象は、

* ファイル名
* 拡張子
* タグ
* メタデータ
* 必要ならファイル内容

とする。
入力中は現在のディレクトリを基準に即時検索。
検索スコープは切り替え可能とする。
例:

```
このフォルダ
ホーム
すべてのファイル
```

## 8. 左サイドバー

左側は固定ナビゲーション領域とする。
セクション構成例:

よく使う項目

```
ホーム
デスクトップ
書類
ダウンロード
ピクチャ
ミュージック
ムービー
```

クラウド

```
zed Drive / Owen Drive
iCloud互換サービス
WebDAV
SMBなど
```

その他

```
最近の項目
共有
ゴミ箱
```

タグ

```
仕事
プライベート
アイデア
参考
アーカイブ
```

各項目にはアイコンを付ける。

## 9. サイドバーの編集

ユーザーはサイドバー項目を、

* ドラッグで並べ替え
* ピン留め
* 削除
* お気に入り追加

できる。
任意のフォルダをドラッグしてお気に入りに追加可能とする。

## 10. メイン表示領域

メイン領域は複数の表示モードを持つ。
最低限、

* アイコン表示
* リスト表示

を実装する。
将来的に、

* カラム表示
* ギャラリー表示

を追加可能。

## 11. アイコン表示

ファイル / フォルダをグリッド配置する。

フォルダ:

```
[folder icon]
書類
12項目
```

ファイル:

```
[thumbnail/icon]
design.fig
2.4 MB
```

画像や動画はサムネイルを生成する。

## 12. リスト表示

行形式で、

```
名前        種類        サイズ      更新日
```

を表示。
列はユーザーが表示 / 非表示を選択可能。
例:

* 名前
* サイズ
* 種類
* 更新日時
* 作成日時
* タグ
* 所有者

## 13. 選択

基本操作:

* クリック → 単一選択
* Ctrl+クリック → 複数選択
* Shift+クリック → 範囲選択
* ドラッグ矩形 → 複数選択

選択中アイテムはsystem accent colorで軽くハイライト。

## 14. ダブルクリック / Enter

フォルダの場合:

* フォルダを開く

ファイルの場合:

* 既定アプリで開く

Enterでも同様。

## 15. 右クリックメニュー

system-owned context menuを使用する。
基本項目:

```
開く
別のアプリで開く
────────
切り取り
コピー
ペースト
────────
名前を変更
複製
移動
────────
タグ
共有
────────
情報を見る
削除
```

メニューはzedBSD compositor側のシステムメニュー仕様に合わせる。

## 16. ドラッグ&ドロップ

ファイル / フォルダをドラッグ可能とする。
ドロップ先:

* 別フォルダ
* サイドバー
* 他ウィンドウ
* デスクトップ
* アプリ

修飾キーで、

* move
* copy
* link

を切り替え可能。

## 17. プレビュー

右側に任意のプレビューペインを表示可能。
選択したファイルの、

* サムネイル
* ファイル名
* 種類
* サイズ
* 更新日時
* タグ
* 簡易内容

を表示。
対応形式例:

* 画像
* PDF
* テキスト
* 動画
* 音声
* ソースコード

## 18. Quick Look

Spaceキーで一時プレビューを表示可能にする。
FinderのQuick Lookに近い。
別ウィンドウではなく、
中央に大きなシステムプレビューをオーバーレイ
する。
Spaceを再度押すと閉じる。

## 19. 最近のファイル

ホーム画面では最近使ったファイルを一覧表示する。
例:

```
企画提案書 v3.key      今日 16:20
デザインシステム.fig   今日 14:03
会議メモ.txt           今日 11:24
背景イメージ.png       昨日 20:18
```

アプリ横断のrecent databaseを利用する。

## 20. タグ

> **削除（2026-10-05、[ws127-p012](../ws127/phase012/phase.md)）**: ユーザー「FilesのTagsは、MacOSのパクリになるので、やめておきましょう。単純に削除でOKです。」この節は履歴として残す。

ファイル / フォルダに複数タグを付与できる。
タグには、

* 名前
* 色
* 任意のアイコン

を持たせる。
例:

```
● 仕事
● プライベート
● アイデア
● 参考
```

タグはサイドバーから絞り込み可能。

## 21. ファイル情報

「情報を見る」で詳細ペインまたは小ウィンドウを表示。
項目:

* 名前
* フルパス
* 種類
* MIME type
* サイズ
* 作成日時
* 更新日時
* 所有者
* 権限
* タグ
* checksum
* extended attributes

BSDらしく、権限やowner情報もきちんと見せるとよい。

## 22. 名前変更

F2またはコンテキストメニューでrename。
選択中のラベル部分だけinline edit。
拡張子は、設定に応じて選択範囲から除外可能。

## 23. 削除

通常削除はゴミ箱へ移動。
Shift+Deleteで即時削除。
即時削除時は確認ダイアログを出す。

## 24. ゴミ箱

専用仮想フォルダとして扱う。
表示項目:

* 元の場所
* 削除日時
* サイズ

操作:

* 元に戻す
* 完全削除
* ゴミ箱を空にする

## 25. デバイス / マウント

サイドバーに接続ストレージを表示。
例:

```
System Disk
USB Drive
NAS
SMB Share
WebDAV
```

mounted / unmounted状態を表示する。
必要ならejectボタンを表示。

## 26. ネットワーク共有

SMB / NFS / WebDAV等に対応可能。
「サーバーへ接続」から、

```
smb://
nfs://
dav://
```

等のURLを入力。

## 27. クラウド統合

クラウドストレージはローカルフォルダと同じUIで扱う。
状態表示例:

* synced
* syncing
* online-only
* offline available
* conflict

必要に応じて状態アイコンを付ける。

## 28. ホームダッシュボード

起動直後のホーム画面はFinderの単純なフォルダ表示より少しモダンにする。
上部に大きなヒーローカード。
下に、

* 書類
* ピクチャ
* ミュージック
* ムービー
* プロジェクト

などのカード。
さらに下に、

* 最近のファイル
* 最近開いたフォルダ
* おすすめ / ピン留め

を置く。
今のモックアップはかなりこの方向で完成度が高いです。

## 29. 複数ウィンドウ

新しいウィンドウを開ける。
例:

```
Ctrl+N
```

またはフォルダ右クリック:

```
新しいウィンドウで開く
```

## 30. タブ

タブも対応すると便利。

```
Ctrl+T
Ctrl+W
```

タブバーは常時出さず、2つ以上開いたときのみ表示でもよい。

## 31. Undo

ファイル操作は可能な範囲でUndo可能とする。
対象:

* 移動
* rename
* ゴミ箱へ移動
* タグ変更
* 新規フォルダ

例:

```
Ctrl+Z
```

## 32. ステータス表示

画面下に常時ステータスバーは置かず、必要時のみ薄く表示する。
例:

```
3項目を選択 — 42.8 MB
```

またはコピー中:

```
120 / 450 files
```

## 33. ファイル操作の進捗

コピー / 移動 / 削除はバックグラウンドタスクとして扱う。
小さなprogress indicatorをツールバーか通知領域に表示。
クリックすると詳細表示。

## 34. 検索インデックス

将来的にはシステム全体のindexerと統合する。
検索対象:

* filename
* tags（2026-10-05 削除、ws127-p012）
* metadata
* content

FinderのSpotlight相当の役割は、ファイルマネージャとは独立したsystem searchとして実装可能。

## 36. system menuとの統合

あなたが先ほど設計していたXDG menu extensionを使うなら、このファイルマネージャはかなり相性がいいです。
例えば通常時のタイトルバー:

```
[Files]  File  Edit  View  Go  Window  Help             — □ ×
```

最大化時:

```
[zedBSD] | [Files] File Edit View Go Window Help | — ▣ × | desktops | status
```

という形。

## 38. 見た目の設計原則

このファイルマネージャは、
「情報量は多いが、見た目は静か」
を目標にするとよいです。
つまり、

* 常時表示ボタンは少なく
* 詳細操作はメニューに逃がす
* 余白を広めに
* 色は選択状態やタグだけ
* サムネイルを活用
* すりガラスは背景に使い、本文は可読性優先

というバランス。

## 39. 一言でまとめると

zedBSD File Manager は、
Finderの操作モデルをベースに、Windows Explorerの実用性と、zedBSDのフローティングUI・system menu・タグ・Quick Lookを統合したファイルマネージャ
という位置づけが一番しっくりきます。
特に今のモックアップだと、ホームを単なる $HOME の内容表示ではなく「ファイル作業のダッシュボード」にするのがzedBSDらしさになりそうです。
